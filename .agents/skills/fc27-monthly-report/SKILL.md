# FC27 月报

先读项目 `knowledge/reporting/fc27-monthly/README.md`。它是Codex与经审核Hermes共用的方法入口；本技能不保存第二份业务规则。

按任务读取：

- 取数、公式、CAC、客户价值、GA4/GSC：`DATA.md`。
- 主判断、对照、归因、图表与行动：`REPORT.md`。
- Coins/Players/SBC、活动、履约和自动化解释：`BUSINESS.md`。
- 报告完成后的知识沉淀、版本冲突、审核与实际学习：`MAINTENANCE.md`。

先固定月度与对照范围，复用同范围完整证据；再核本会话工具schema和现役规则，补足会改变判断的缺项。只声称实际取到的数据和已执行动作。Admin付款销售与Order发货采购毛利分源；广告CAC分母取同范围明确广告来源新付费客户；自然浏览、入口会话、购买事件与GSC点击分别解释。

先给本月主要判断、价值取舍和下月优先事项，再用关键事实支持。历史月报只借组织方法，数值不变成当前阈值；经营成品不含内部抽样、教学或修稿过程。报告只读取证，不因此修改价格、预算、排程或权限；已有明确授权按原范围执行。

交付前核关键计算与来源；若输出HTML，实际检查受影响的图表、切换、键盘、主题和手机阅读。完成后按维护协议提炼稳定知识，复用项目现有closeout，不另建定时任务。内容、Git/CI、审核、目标profile读取、独立迁移和真实报告分别报告状态。
