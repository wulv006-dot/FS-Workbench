# 导航竞态与首屏缺失修复（2026-11-03）

用户反馈推翻了上一轮“导航已统一覆盖”的验收结论。上一轮入口检查没有覆盖旧脚本晚到后再次改写DOM，不能作为持续状态验收。

## 已确认原因与修复
- Hermes静态页同时加载hubnav.js和nav.js。增强先完成时，旧nav.js使用heading.parentElement.replaceWith替换增强后的行，留下原子菜单并插入旧分组，造成重复、按钮消失、数据分析展开。新nav.js在增强已接管后跳过旧分组/选中态重建；结构观察器兼容旧缓存脚本晚到，只修复破损结构。
- 增强原先等待DOMContentLoaded，FC等页在其他延迟脚本未完成时仍显示旧导航。现在有导航即可同步增强。
- 商品编辑的导航原先在页面底部、阻塞业务脚本之后注入。活动代理页面与FC金币页提前在body开头加载导航；共享head预加载同版脚本。业务请求、权限与定价不变。
