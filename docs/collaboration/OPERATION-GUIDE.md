## 七、异常一律先停写

看见 `authentication failed` / `403` / `protected branch`：停，不换token/放宽权限/禁用规则。`non-fast-forward` / `conflict`：先fetch、对照双方差异，不能forcepush。SHA不一致或出现其它模块：停并请对应owner确认。扫描发现秘密：不输出值、不上传、不测其有效性；若已泄露，交owner另行处理，不用删一行掩盖历史。生产读回失败或unknown：保留证据与旧ID，暂停写和重试；不能靠旧包盖回。任何未验都写明阻断的是“入库、合并还是该模块上线”，不把准备稿当完成事实。
