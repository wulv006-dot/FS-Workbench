# 双方协作操作入口

唯一规则：[HOTFIX](../ops/HOTFIX.md)。不另建“当前流程”、两方逐SHA确认或全仓QA门禁。

发任务用一句话即可：“由<负责人>修复<真实入口的行为>，范围<模块/路径>，按已授权合同完成相关检查、备份发布和真实使用确认。”

AI据此复现、最小修改、跑直接检查、连续实施范围内动作。范围确实不足或平台明确拒绝时，报告具体动作及所缺授权，避免让用户反复重复同句批准。

交接记录目标、PR/线上版本、实际结果、未完成事项；截图、长报告和无关回归后补。大超与吴律使用同一规则，各自模块owner和身份边界保持，[OWNERS](OWNERS.json)不是ACL。

[旧手册](https://github.com/wulv006-dot/FS-Workbench/blob/ee8f36b6861d2f568692a7b333a8efe403e5551a/docs/collaboration/OPERATION-GUIDE.md)仅作历史证据；旧服务器上传步骤、套餐未知、逐次双人确认和模板中的另批要求不再是普通已授权任务前置。
