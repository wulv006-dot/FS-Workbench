# 飞书 Codex 的 GitHub 工具预授权

2026-10-25 用户授权飞书 Codex 补齐提交、创建 PR 与合并的工具预授权，并明确在不能按仓库限定时允许全局 GitHub 写入审批放行。现有 GitHub 连接覆盖该账号全部仓库，因此采用本机 Codex 的 GitHub connector 专用默认工具预授权；不改变其他插件的审批策略，不新增账号、凭据或 GitHub 管理权限。

本次仅修改工具审批配置。业务操作仍按用户的任务范围与项目规则执行；FC 自动改价故障沿长期授权，允许先受控恢复生产，但必须在上线后六小时内补齐与现场一致的 PR 和必要 CI。

FS-Workbench 的 main 仍沿原 main-pr-fast 规则：必须通过 PR，pr-fast 成功并满足最新 base，禁止强推和删除，无 bypass。本说明与工具预授权都不允许跳过 CI、改分支保护或扩大业务范围。

通信服务只在没有执行中的飞书任务时重载。本说明通过现有 GitHub 原生工具建立一份文档 PR，用于验证提交、建 PR、正式 CI 与正常合并；具体 PR、head、CI 和合并回执记录在本次本地验收资料中。文档不触发生产发布、采集、模型定价或业务写入。
