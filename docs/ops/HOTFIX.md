# 普通 Bug 60 分钟执行规则（2026-10-07）
适用双方 AI。用户本轮“允许并启用”授权本流程入库、验证后启用 main 规则；生产本轮不动。普通小修优先于 AGENTS/手册历史逐 SHA 人工审批段落，重大/越权事项仍遵守既有合同。

## 每次任务
单负责人、一个分支、一个 PR；吴律负责 FC/NBA/MLB，陈超负责 D4/PoE2/Aion2。共享改动列消费者；对方协作提供信息/测试，不要求两内部人逐个 Approve。Git 写入与生产发布各保留一个执行者。

| 从发现起 | 必须完成 |
|---|---|
| 0–10 分 | 复现、影响/风险、owner、活动源与线上 SHA、现有业务授权 |
| 10–30 分 | 最小修复；在同一 PR 更新，避免重建 PR/workflow |
| 30–45 分 | 自动 pr-fast 必要快测（当前实测约1分钟，预算5–10分钟）、锁内核基线/备份/现有受控入口发布 |
| 45–60 分 | 原 Bug 与关键邻接行为线上冒烟、读回版本和真实结果 |

预计无法60分钟闭环即报告原因/阻塞/预计，不等最后一分钟；60 分未闭环必须报 **SLA 超时/未修复/部分成功/unknown** 和下一动作，不把 merge/200/静态检查当上线成功。现有任务持续执行，不需另造调度平台；无人值守的到时通知只有现有调度/通知入口配置且实际验过才可声称。本流程未创建无人值守 SLA 告警器。

常规通道：PR自动CI→原模块publisher→线上冒烟。紧急恢复通道：在既有业务修复授权与发布合同内，完成原Bug/关键邻接风险必要检查后受控最小发布，再异步补齐PR/回归/归档；Git合并仍满足实际main规则，不旁路检查或工具拒绝。两通道均单发布者、保留备份/现场基线、真实读回；缺授权/入口仍报BLOCKED。

## CI 与合并
一个复用 pull_request 工作流、稳定必需 job `pr-fast`；每次新 SHA 自动运行，取消同 PR 旧 CI。测试隔离网络且无生产/秘密/部署；必需测试 >0、0 failure/error/skip，异常和超时非零。分发器/流程文件的独立修正只跑门禁和路径自测；未改的业务源码复用同源先前证据，不重跑旧业务 suite。CI 运行于 PR 合成合并树，证据记录 head/base/实际树/运行环境；同一 head、base、输入和环境复用成功证据，不反复 rerun。base 改变只重评组合影响；全回归、长报告、截图、归档异步补做，不能拿旧清单卡新修。

代码测试入口在 tools/pr_fast.py：FC 根/恢复、Players 文件锁、D4/PoE2 纯闸门/取整、Aion2 状态、NBA 身份守卫已登记。输出测试模块与路径；其它代码未映射会失败 UNMAPPED，最小补测与映射在原 PR 完成，不新增工作流。JSON 做解析；文档只做流程入口自检。HTML/CSS 当前没有已核实的静态校验器，包含这类路径（含混合 PR/删除）会明确 UNMAPPED，不能仅靠 selfcheck 假绿；在原 PR 补最小受影响验证入口后才放行。此处不宣称 HTML/CSS 已覆盖。其原问题仍须负责人复现/冒烟。此映射不证明仓库路径是当前生产源，冻结候选不原地修改。

低风险且在既有业务授权内：负责人读差异、归类并启用 GitHub 原生 auto-merge；pr-fast 真通过即可合并，required approvals=0。P2 建议默认非阻断；实际故障按影响分级，复现失败/原 Bug 未修复阻断。P0/P1、跨业务边界或缺业务授权升级一次，批准后普通步骤持续有效。AI/Codex 机器人 quota 不作门槛。

main 要求 PR + GitHub Actions pr-fast 通过；禁止强推/删除、无默认 bypass；无必须两人 Approve/签名/部署检查。严格最新 base，避免未经检查的新组合；普通 AI 不能临时关闭规则补救。仓库 private 和已有 auto_merge=true 保持。已于08:15:30 UTC实际启用main-pr-fast规则集24637210；API核实上述规则，仍以未来实际读回为准，不重复保存。

## 发布风险边界
合并不等部署。动态采集数量、系数及竞品价的正常变化，不要求等待历史失败输入恢复；新计划读取当前合法数据，原失败证据保留、旧计划不重放。已授权业务修复按原单模块发布合同自动推进，绑定 source/artifact/现场基线、备份回退、release 锁和读回；不得要求用户反复同句授权。价格/登录/凭据/不可逆事项保留真实身份、来源、范围、幂等、回滚兼容和读回；unknown 先查原 ID，不能盲重放/换 ID。保持业务数据/队列/锁/回执/政策，不拿旧包覆盖。版本、source/artifact SHA与manifest由现有CI/发布入口自动记录和读回，不要求人工重复手抄；若实际入口缺失自动记录能力，明确未完成并补最小记录。仅保留两个复用入口：本PR的CI已实现，生产publisher沿用既有模块受控入口，当前测试分发器不代表生产publisher已搭建。不得新建广泛生产密钥/SSH/GitHub secret；不绕工具拒绝。

环境失败先确认一次事实，使用已允许路径；遇安全拒绝按原因修复或告警，不能换工具规避。费用边界：GitHub Pro 已实际月付 $4；2026-10-07 核 Actions 10/3000 分钟、存储0/2GB、净 $0；Actions预算 $0/stop=Yes/含用量提醒On。CI 不加收费服务或包，每 Bug 不重复 quota 勾选。额度耗尽明确 BLOCKED，不能假绿或自动购买。
