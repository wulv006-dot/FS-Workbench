## 实现

- `serp.py`由FS程序直连Bright Data SERP，独立于Hermes及AI开关。固定Google关键词、国家、语言、桌面设备、可选位置与观察日；每次响应解析所有竞品。只数自然结果，不使用含广告的global_rank作为自然名次。保留有效深度；深度不足、未找到、失败分别记录，不补101或0。
- 请求前记录授权、原请求键和提交时间；成功响应只保存精简结果，重复执行复用。pending/unknown不自动重发；401/402/403/429等源级错误停止该源，不停止基础来源。免费月池授权按月记账，不建立新计费平台，不消费未授权现金余额，不充值、绑卡或升级。账面请求回执不伪称供应商费用实账。
- 国家配置位于`mmoexp_google_data/seo/sources.20261105.json`。每国先取本游戏金币/币类主商品的3个核心词，四游戏共96组合/日，31天2976请求，给校准及异常留余量；这是起步词表，后续可在已授权范围内调整。实际保护上界来自5000免费月池，不沿用旧200请求/5日期等参考值。独立gid、MMOEXP商品目录与竞品域名分开核对，G2G/Eldorado仅作为SERP竞品，不计入主站经营数据。
- `calendar.py`读取现有已发布游戏监控资料、经用户接受标记的FC27活动表，并在原SEO夜间批次中复用现役FS官方源解析器读取指定EA、Blizzard/Steam、Aion2来源。只调用无模型的fetch/parse层，不启动原全游戏collect、不调用模型、不修改游戏监控服务。原发布时间、原读取时间、事件日期分开；没有可靠事件日期的公告保留“日期待核”，不把发布日期当活动日。
- FC27未来活动全部保留原起止日及原表来源说明，统一标记用户提供、未独立核验；原表“官方确认”不提升为本次官方核验。WowForever只保留独立gid1367和wow-forever商品路径，其官方公告版本归属仍缺明确依据，暂不导入全WoW信息。
- 新增`markets`与`calendar`只读接口，权限、分页及facts_hash均复用同snapshot。前端展示八国、七竞品的实采状态，以及有日期和待定日期资料；保留来源链接、明细与主题，无刷新采集入口。

## 夜间、资源与恢复

仍是一套03:20批次。昨日与近期修订数据先采，随后观察资料；每个新请求前检查资源及夜间收尾时间。已完成的独立观察页立即保留，后续条件没完成也不会丢掉有效样本。T日观察仍到T+1正式快照显示，白天注册配置不充作排名采样，不改当前快照。

复用现有187资源区间与600秒发布收尾余量，HTTP区分连接/无进展超时并保留实际最终截止。有进展的读取不机械按旧240秒结束。SERP和日程不会用尽发布收尾时间。只清SEO自有35天事实；有效授权的用量回执在事实清理时保留，授权过期且足35天后才清理，避免清理重置消费计数。原快照与两份验证备份机制保留。

每日服务可选读取FS受控Bright Data凭据，Web进程不接收该Key。凭据未入库；配置JSON只含环境变量引用。无Key、无SDK、Hermes未运行时，基础冷启动与固定快照读取不受影响。
