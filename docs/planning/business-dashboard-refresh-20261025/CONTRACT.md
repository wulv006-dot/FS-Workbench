## 主展示

默认恰好八张大卡，依次为：销售额、订单数、毛利（¥）、毛利率、新客人数、复购率、新客占比、客单价。销售额和客单价为 USD；毛利为 CNY。完成成本覆盖、待补成本、未完成订单、其他统计及详细来源收进补充指标/口径展开区。亏损保留负值；未提供不填 0。

逐单实际成本毛利：按付款时间，Admin同网站同批已付款未退款的已完成订单，整单人民币收入减同网站同订单号 Order 历史实际采购成本；缺成本、未完成单单列。毛利率用已核群体总毛利除对应 Admin 人民币收入，不平均订单/游戏/每日比例；不是净利润。FC客户等未核成本细分不套整游戏率。逐日金额和数量加总须等于区间值；只画完整日。Hermes按需能力保留：发货统计按其交易群体独立读取，不补缺成本或缺日。

新客人数、复购率及新客占比沿用已核 Admin 原生字段与范围；不把复购率改成订单占比，不跨日相加人数。原始 new_people / total 的新客占比定义保持并在折叠口径中说明；未单独核实主站/区服的字段继续标注真实来源范围。订单客单价（AOV）使用同范围 Admin 已付款销售额 ÷ 已付款订单数（USD），付款记录保留、退款另列；零订单不计算，缺项不引用 Order 参考平均值。原生 customer_price 对应付款客户均额（ARPU），保留原值并明确标注，不作为订单 AOV。

## 缓存与刷新

同一账号权限、网站、游戏、类目、区服、时间及口径的旧值先展示；顶部独立小字“刷新中…”，完成后替换，数字不拼接过期文字。切换范围不带入原范围值；权限拒绝清除该来源数据；失败保留同范围最后成功值并提示重试，缺项不补旧字段冒充成功。

| 来源/字段 | 变化原因 | 打开页面时的核验周期 |
|---|---|---|
| 当日销售、订单、新客、复购、客单价及结构 | 新订单/付款/退款/后台更正 | 15 分钟 |
| 历史同类经营汇总与结构 | 可能迟到付款、退款、更正；无上游封账证明 | 2 小时；期间复用准确区间缓存 |
| 实际采购成本、毛利、毛利率、覆盖、未完成状态、逐日曲线 | 交付推进、迟到成本、退款或状态更正 | 10 分钟；主站历史订单成员至少每2小时完整重核，避免完成状态永久封存 |
| RS 当前问题单/未支付 | 当前积压，不是历史支付日事件 | 独立5分钟缓存；网站/类目/区服一致，不受所选支付日期截断 |
| 有版本号的已保存报告、原始快照、失败/UNKNOWN回执 | 审计事实 | 原版本不变；新读取形成新版本 |

历史日期不等于数据永远不变。原支付时间、金额等已读取事实可以复用，但不能据此把当前可退款/可更正的原生统计永久冻结。无实时推送承诺：沿原有页面可见性、手动更新、共享锁、冷却、限流与读取预算；不新增定时采集、登录、通知、改价或调度。
