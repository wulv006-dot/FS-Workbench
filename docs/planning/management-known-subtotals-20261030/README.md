# 经营管理台：缺项时保留已知汇总

当一个项目月累计缺失时，原严格求和令全盘、运营组及当前列表合计全部为空。修复只在这三个前端汇总位置显示已知小计与项目覆盖数；缺项不作为零，全部缺失仍显示未知，实际为零仍是有效值。

每个指标独立计算覆盖数。覆盖不完整时，正式完成率、参考利润率、组进度及月末预测继续未评估；不把部分实际除以全部目标，不增加“已知项目完成率”。完整覆盖、原项目行、目标、负责人及已知项目健康判断沿原规则。后端事实、AI、目标配置、定时任务及采集均不改。
