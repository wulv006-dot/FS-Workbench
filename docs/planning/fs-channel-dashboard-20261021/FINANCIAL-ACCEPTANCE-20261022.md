# FC收入口径与采购毛利核验（2026-10-22）

## 生效方法

Admin整单原人民币收入按订单计一次；Order只补实际采购成本，按有效发货记录ID去重累计。同一已完成且收入/成本可核算群体：采购毛利=收入合计−采购合计，综合利润率=采购毛利/该群体收入。不平均订单率，不把发货商品行销售额当整单收入，不用固定汇率补人民币，不将未知成本补零。未完成、欺诈、实际退款、测试及确认零成本商品分别按业务基准处理；退款申请不等于已退款。

依据是收入与对应销售成本匹配的通用方法；IAS 2说明售出存货的账面成本在对应收入确认期间转为费用（[IFRS官方说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/)）。本模块只有已核采购口径，支付费用、退款实结、广告和其他费用未完整，因此不声称满足全套财务报表准则或得到净利润。

原审计、冻结样本、最新归档及原生统计分别保存，不拿不同快照硬对齐。脱敏PR只包含规则和合成测试；真实订单及金额在项目忽略的受控审计目录。

- 固定完成群体：收入字段纠正与缓存纠正分开计算。旧缓存成员及晚到成本先修；随后以Admin整单收入替换发货收入。差额来自已查实字段，不据商品金额拟合公式推断后台分摊或历史汇率。
- 后续原完整成本读取自动剔除了旧成员并保留当前跨天替换成员，订单只计一次；无需再次补写源单或强行保留旧交易日期。
