# Admin整单收入与采购毛利合同（2026-10-22）

## 来源与计算

Admin原生统计维持经营总盘。渠道逐单核算采用Admin订单amount_usd_format与amount_rmb_format；Order仅补该单实际发货采购成本。Order订单概览、商品行与发货销售额不是同一字段，后两者不得替代Admin整单收入。每笔Admin收入仅计一次，成本按有效主站订单发货记录ID去重、累计；同一已完成且收入/成本已核群体，用总收入减总采购计算采购毛利，再除同群体总收入，不平均订单率。

这是采购口径毛利。支付费用、退款实结、广告等不完整时不称净利润；不将完成覆盖单率套用于未完成付款单或全站。其他经营总盘缺完整成本时仍将原参考利润明确作为估算另列。实际亏损保留，不因执行策略红线改写历史。

## 状态与迁移

验证未通过为欺诈，从经营数、收入、客单价与占比分子分母排除；原状态和明细保留。退款申请不等于实际退款；已核支付退款或已退款状态继续排除。用户确认测试及精确历史零成本商品规则保持，SCM缺口不补零。

旧缓存缺Admin收入字段时整段沿旧法，并明确标回补，不与新法混算。完整分页、身份/来源/时间及重复校验通过后整段切新。缺原人民币金额不以USD乘固定汇率/Order子单销售额代替；成本可保留，毛利未知。完整新日归档仍复用，后台补晚到成本，失败保留上份完整证据。布局、权限、定时器、采价、策略、开关和生产写价均不变。

## 核验边界

同一真实订单在Admin及Order订单概览的整单金额一致，Order商品与历史发货金额不同；字段差不是成本遗漏。商品分摊/金额封顶机制与历史汇率时点仍为独立待核，不能将拟合公式写成源合同。回归包括多次发货收入只计一次、收入与成本独立缺失、欺诈排除、退款申请、旧缓存迁移及原权限/加载/主题/移动布局。上线与真实三边复核另以原发布回执和验收记录为准，本文存在不代表发布完成。
