# 万圣节活动运营看板修复

用户要求已发布活动能够明确定位并查看真实追踪数据。本次仅修改现有活动模块；不改变优惠规则、商品售价、奖池、活动截止、优惠码截止或账号权限。

- 默认定位已上线的 `mmoexp-seasonal`，正式访客数据为默认来源。草稿留在管理区，不删除历史登记或记录。
- 展示访问、匿名访客、翻牌、选购、确认加购及分游戏表现；商品名来自当前已发布商品映射，记录标识放在展开信息。
- 展示查询结果时间、当前筛选实际收到的事件数与最近事件时间；孤立事件与访问批次统计分开，不能用查询成功代替采集成功。
- 仍按 UTC 日期筛选，结果时间显示北京时间；活动结束显示美东时间。支付及收入归因尚未接入，不能显示为真实 0。
- 统计同意入口移至活动页头下方，保留明确同意、拒绝、撤回及不影响购买的原规则。未授权/被拦截的历史访问不能补造。
- 每分钟在可见页面检查一次，正式 PostHog 查询仍由原五分钟缓存限制，未新增服务器定时任务或费用。

验收应分别覆盖：纯逻辑与字段边界、隔离浏览器、精确 CI、原发布器实际回执、生产读回及标记事件收数。不能将隔离样本、历史联调或新的标记验收当作正式用户流量。真实支付未执行。
