# 未用优惠红线与平均毛利估算（v14）

2026-10-22用户明确修订：所有合法优惠均豁免折后10%采购毛利要求，允许平本或亏损拉新。此口径覆盖v13“最差合法优惠组合仍须10%”规则，不追改历史账本。

10%服务器硬线仅作用于未额外使用优惠的实际套餐售价，成本仍包括全部交付及赠送金币、所有套餐、整数K自定义量和舍入。套餐原固定数量/价格公式保持。VIP、积分、折扣码、优惠券仍互斥；本次不创建、扩张或更改优惠。手工、恢复和Hermes共用同一核算，均不能绕过未优惠10%底线。

主卡显示“估算平均采购毛利率（100K）”。历史取最近七个完整日的主站FC Coins已支付有效订单，匹配已有ES实际优惠USD，排除退款/欺诈/测试；留存比例为订单USD总额÷（订单USD总额＋实际优惠USD总额）。不平均订单百分比，不用券关联占比冒充核销率。当前100K实际套餐价乘留存比例，再减当前全部交付成本，所得毛利÷估算收入。

这是固定100K套餐在历史优惠力度下的情景估算。当前档案没有完整平台和套餐数量拆分，使用全Coins优惠结构，不能冒作平台实测、全目录组合收益或未来需求预测。披露窗口、样本覆盖和来源时点；缺失不补零，不因经营研究缺数停正常自动化。估算亏损照实显示，零收入的毛利率未定义，不能显示为0%。

已实现：执行/恢复共用未优惠证明、历史优惠加权、工具与Hermes知识及原页面布局内指标调整。旧报价因核算依据不同只能保留为历史；新执行必须重采当前成本、竞争价、汇率和优惠/数量合同。保留原锁/CAS、UNKNOWN、120分钟周期、开关、其他商品公式及售后补偿独立账务。
