## 固定流程

1. 范围与来源：FC Coins、期间、平台、净收入、真实成本和优惠组合。
2. 执行与暴露：后台确认不等于前台已被客户看到。
3. 三本账：历史采购毛利、当前候选核算、同口径广告后贡献；币种和时点分别保留。
4. 候选比较：保持、原引擎基线、研究涨降价；先找最小必要变动，盈亏平衡销量是条件。
5. 组合约束：PS/Xbox共同供应成本、互通市场和共同基础价，按合法成交组合核验，PC独立；主改价与尾价预算分开，各合法优惠情景逐项检查。
6. 反证与复盘：提出竞争解释、最小补证、撤回条件和观察窗口。

程序出版本、来源和hash可读回的固定核算回执；Hermes负责解释、假设与反证，不用文字重算覆盖程序。声明情景始终是假设，不是已核市场价。真实成本、当前可比竞品和覆盖不足时不给新的具体可执行售价；研究缺项不会停用现有自动化。
