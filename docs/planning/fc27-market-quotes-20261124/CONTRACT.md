# FC27 普通购买档竞品报价迁移

范围为现役 V6 定价。PS、Xbox、PC 各有小额和大额两个锚，分别采用普通客户无需领券可买到的 100K 和 1000K 商品售价。常规商品自带的赠币留档；另选的加赠档、新客、用券、限时促销档退出市场比较。相同购买档直接比较 USD 售价。我方成本按实际承诺交付数量核算。

Lootbar 和 U7Buy 维持市场走廊与原报价缺失规则。U4GM、IGGM 由独立观察任务分站展示同档商品价差。两站不进入候选价、市场锚、保险、写前验证或改价准入。市场保险仅使用定价来源，继续按实交量核算。Arab‑UT 退出 V6 新采集及提示，旧记录按原版本解释。定价来源每个平台优先采用当轮实采 1000K；缺失时允许用同轮有效普通 100K 售价乘十，证据须标记估算。冻结时间、15 分钟有效期、近三自然轮中位数和七日成对比值按相同量段计算。

187 主采，183 补缺。若两者都缺同轮 IGGM 或 U4GM 普通报价，Windows 主动通过专用 SSH 身份向 187 领取该站缺项并回传。按平台、购买档补缺，保留较早节点的有效报价。本机只读，不持有后台或写价身份。三个节点均未取得的数据保持缺失；来源拒绝及限频按既有来源合同处理。两家观察站缺价时，可独立发布和使用已验证的 Lootbar、U7Buy 及定价规则。

保持现有小时节拍、财务零线和双篮 18%、经营目标及其计划参数、单轮和 24 小时保险、活动优惠保护、187 唯一写价入口和原 ID 对账。V6 按本次 Admin 成功回执及 MMOEXP 主站（site 266）完整价表读回确认。历史操作、冻结回执和来源范围保留原语义。

上线验收使用新旧采集在相同有效覆盖下的整轮时长、峰值内存及浏览器启动次数，同时核对市场取价、财务证明、监控读回与首个自然轮。仓库中的实现和离线回归不能证明现场切换。
