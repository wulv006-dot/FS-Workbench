## 一、核心结论：模型和产品是**两个独立步骤**

| 步骤 | 接口 | 作用 | 本次实测 |
|---|---|---|---|
| ① 建模型骨架 | `POST /admin/goods.GoodsMould/add` | 只写 `goods_mould` 一行 | ✅ 成功（mid=44638327），**产品 0** |
| ② 上架产品 | `POST /admin/goods.GoodsMould/shelves` | 按 `site_ids × aids` 生成 `goods` 明细 | ⏳ 待验证 |

**⇒ `add` 不产生产品，这是设计如此，不是 bug。**
FC 的 `importPlayers` 之所以"一条龙"，是因为它后端内部**先 add 再调 shelves**。

## 三、产品的数据结构（实测）

## 四、完整自动化链路（MLB 版）

```
1. 读 Excel（球员表）→ 逐行拿 title / price
2. POST /admin/goods.GoodsMould/add        → 建模型，回读拿 mid
3. POST /admin/goods.GoodsMould/shelves    → body 带 mid + 全量 site_ids + aids → 建产品
4. 回读 /admin/goods.Goods/index?search[mid]=mid → 校验产品数 == 预期
```

### 上面 4 个待验证项的答案
1. ✅ **site_ids/aids 确认**：`all_site_ids`(15) / `all_aids`(3) 来自 `GET /edit` 的 `row._extend`；
   加上主站 `site_id=0` → 16 × 3 = **48**
2. ✅ **`shelves` 是赋值式而非累加式**：`add` 后产品 0，`shelves` 后 48，一次到位
3. ✅ **不要求预先 `is_put=1`**：`add` 时 `is_put=0` 也能建产品；
   而且 **`shelves` 会把 `is_put` 自动置 1**
4. ✅ **aids 确为 3 个区**：`19897` PlayStation 5 / `19899` Xbox Series X|S / `19901` Switch

## 七、★ 图片 + zh_title 链路（2026-10-12 同日打通）

### 7.1 为什么必须补
老大指出：**自动改价脚本依赖 `icon` 和 `zh_title`**。少了这两个字段，卡即使建出来也是废的。

### 7.2 `zh_title` 的真身
```python
# 执行器 client/mlb_agent.py:758 / 767（原文）
"%s%s-baked-sm.webp" % (icon_base, card.card_hash)   # 第 5 列 图标地址
"zh_title=%s" % card.card_hash                        # 第 15 列 扩展属性
# icon_base = "https://cards.theshow.com/mlb26/"
# card_hash = showdd item_url 里的 /items/([0-9a-f]{32})
```
⇒ **`zh_title` 的值 = 卡图 URL 里的 32 位 hash**，二者同源。
后台落地位置：`more.extend = [{"key":"zh_title","value":"<hash>"}]`

**三方对齐验证**（Rafael Flores）：
| 位置 | 值 |
|---|---|
| xlsm 第 5 列图标 | `.../mlb26/b08632a0710d3c63701c05c…` |
| xlsm 第 15 列扩展 | `zh_title=b08632a0710d3c63701c05c35de0fe06` |
| 后台 `more.extend` | `b08632a0710d3c63701c05c35de0fe06` |

### 7.3 图片上传：两套接口（`b2c-api.p2pah.cn`，**不是 admin-api**）
| 接口 | 鉴权 | 说明 |
|---|---|---|
| `POST /upload/network?pic_list=<url>` | **无** | 外链图 → 内部附件，**幂等**（同 URL 同 id） |
| `POST /upload/file`（multipart，字段 `file`） | 需签名 | `token=md5(str(ms)+"DFSAF[WFKWEFL;SDFJKSDLF;JF")` + `timestamp=ms` |

响应结构：
```json
// /upload/network
{"upload":{"network":{"code":200,"file":{"id":16417939,
   "full_url":"https://b2c-static.p2pah.cn/images/202610/xxx.webp"}}}}
// /upload/file
{"upload":{"picture":{"code":200,"file":{"id":16417925,"full_url":"…","suffix":"png",…}}}}
```
⇒ `icon = file.id`

## 八、最终完整链路（生产级）

```
输入：执行器任务结果 JSON（cards[] 含 hash / sale_price / product_name）

① POST https://b2c-api.p2pah.cn/upload/network?pic_list=<卡图URL>  → icon(附件ID) + full_url
② POST /admin/goods.GoodsMould/add   （body 直接带 icon + more.extend=zh_title）

④ POST /admin/goods.GoodsMould/edit   （补 icon + zh_title，字段不齐时才发）
⑤ POST /admin/goods.GoodsMould/shelves（site_ids15 + aids3 → 48 产品，自动 is_put=1）
⑥ 回读校验：icon>0 且 zh_title==hash 且 产品数≥48

幂等判据：上述三项全满足 → 跳过
```
