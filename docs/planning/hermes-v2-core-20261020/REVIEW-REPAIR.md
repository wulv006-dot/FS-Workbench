# 学习候选校验失败后的局部修复

认证管理员可对failed事件提交人工审核候选：沿用原attempt，事务内校验来源/文本/有效期，保留previous_review，不再调用模型，不自行发布。非法候选回滚到原failed状态；unknown仍须原ID对账，不接受人工修订跳过对账。queued原路径保持。

验证：4项本机回归通过，覆盖原失败形状、已结算回执且无私有正文、原attempt人工修订、不自动发布、非法修订事务回滚、unknown与非管理员拒绝。PR/正式CI/合并/生产发布/真实修复验收分别记录，未部署不得称上线。
