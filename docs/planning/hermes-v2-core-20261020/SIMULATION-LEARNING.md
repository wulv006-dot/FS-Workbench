# 模拟事实进入教学复盘

真实研究1e1ae3d3已完成，14次max模型调用，保存4份草案和2份只读模拟。报告把基线报价混作实际售价，并误称未计入本店赠送；原模拟明确包含5K赠送。这是分析解释缺陷，不能把数值计算通过当作经营判断通过，报告不构成获准策略。

本补丁只补两处证据接线：模拟回执显式给出同一快照实际包价、原引擎基线包价、候选包价、赠送、快照原时间和计价单位；教学来源从原任务库读取本人、同一已完成任务的原模拟，附为有hash和覆盖的独立事实。只投影三平台数值与来源身份，不复制订单、客户、原始报价目录或writer载荷。基线是原引擎计算结果，不等于当时实价；购入1K与含赠送的到手1K不同。

旧模拟原字节和原ID保留。旧回执没有明示实价时标missing_in_original_receipt_do_not_infer，不回填、不反推或改写旧模拟。最多20条原任务模拟，数量与实际包含数独立标注，原聚合白名单及12KB/48KB限制继续。

28项相关回归覆盖原公式/底线/联动/源冲突/研究权限、教学敏感字段排除、原失败/unknown对账，以及新实价/基线/赠送字段、同任务同owner隔离、旧回执缺值和两目标发布边界。仅补事实输入；不能据此宣称模型已经会正确使用证据。新增候选仍须评审，独立新问题和负责人盲评另验。
