## 已批准设计

FC 复用 RS 连续分区与主题：筛选 → 概览 → 利润率与销售趋势 → 结构分析 → 用户与消费 → 组内项目对比。去除 FC 五分页组织，保留重要履约摘要和日报入口。组内项目对比只在全部商品显示。

分类：全部、金币、球员卡、SBC、Packs、其他。完整商品识别后，整单唯一归属 `球员卡 > SBC > Packs > 其他（含代练） > 金币`；未知/冲突不硬归类。销售、消费、趋势、导出共享整单归属。RS 更多筛选方式展开平台，保留未知/多平台。

利润来自 Order 发货统计交易时间，以站点+订单号关联整单分类。人民币毛利=发货销售额−采购额，毛利率=组内总毛利÷组内总发货销售额；不平均单率。这是订单组毛利。分批发货按发货记录唯一身份去重，未知、无关联、缺成本和跨平台透明。Admin 付款美元收入独立，不用于冒充发货人民币利润。

结构增加分类销售/订单占比环图、随日/小时粒度切换的分类趋势。用户消费保留原口径、表格和下钻，增加柱状/环形/折线呈现。新老客和终身价值不足的数据不伪装完整。
