# 阶段交接与监工记录模板

## 阶段交接

| 字段 | 应填写内容 |
|---|---|
| 阶段与工作要求ID | 用于避免重复派工 |
| 起始与交付版本 | 实际提交、PR、合并状态 |
| 合同与配置 | 使用版本及变更影响 |
| 完成功能 | 对照原任务和本阶段目标 |
| 验证 | 实际运行环境、命令/操作、结果、证据 |
| Q审查 | 指定版本、发现、修复与复核结果 |
| 发布 | 实际目标、构建/运行版本、地址和读回；未执行如实填写 |
| 四种状态 | 界面、后台数据、187、真实交易分别填写 |
| 阻塞与下一步 | 解除条件、负责人、仍可推进的工作 |

## 老D监督记录

记录关联工程任务、最近已检查交付、对应提交/配置版本、当前阶段、证据缺口、已发送的后续工作要求ID、用户决策和下一次检查条件。不要把工程主控的“完成”直接复制成监督结论。
