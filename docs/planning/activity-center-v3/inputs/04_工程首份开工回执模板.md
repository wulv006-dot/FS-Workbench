# 工程首份开工回执模板

| 字段 | 应填写内容 |
|---|---|
| 项目与工程任务 | 实际项目标识、本地任务ID/链接、创建/接管和老D后续指令执行结果 |
| 原任务一 | 接受版本、全部页面/功能、源码与素材位置 |
| 原任务二 | 接受版本、全部页面/功能、源码与素材位置 |
| 排除项 | Matchday/竞猜/竞猜奖励 |
| 代码基线 | 仓库、分支、提交、未提交改动与归属 |
| 开发环境 | 主控实际本机主机名/项目路径、辅助环境、依赖、工作树和基本运行结果 |
| 真实后台入口 | 已验证能力及待补条件 |
| 187发布入口 | 原本机SSH的只读连通结果、目标识别与现役版本，或准确缺口 |
| 第一批任务 | 负责人、允许修改范围、输入、完成条件 |
| 待补材料 | 具体缺口、影响阶段、仍可推进事项 |
