## 一、确定的业务结果

本轮用户补充的定位为：Lootbar与我方量级接近且品牌更老，我方增长更强；U7Buy是高端、成熟、广告与影响力最大的BtoC金币网站；ItemD2R为新兴AI采价/定价/发货模式，商业方式与我方接近。把这些标记为用户提供的业务前提，不冒充第三方份额审计；不将我方增长、竞品品牌年龄或“使用AI”自动换算成额外加价、可信度分或销量预测。

确定采用 Lootbar 80%、ItemD2R 15%、U7Buy 5%。IGGM、U4GM直接数字权重为0，原采集、显示、缺项记录及定性分析仍保留。原80/10/10是已替代的提案，旧0.6/0.7/0.8为既有研究情景，不可混作生产配置。

按每个平台的同量有效报价：

```text
L = Lootbar美元金额 / Lootbar实际交付K × 我方实际交付K
dI = ItemD2R同量指数 / L − 1
dU = U7Buy同量指数 / L − 1
aI = 有效ItemD2R ? 0.15 × clip(dI, -0.05, 0.05) : 0
aU = 有效U7Buy   ? 0.05 × clip(dU, -0.05, 0.05) : 0
raw_weighted = L × (1 + aI + aU)
```

每源资格使用原合法来源合同，计算使用十进制定点金额；缺项贡献为0且保留原因，不补旧价、不按存活站点重新分配、不把缺项伪造成已观察到L。U7Buy缺失时ItemD2R仍15%；ItemD2R缺失时U7Buy仍5%；两者缺失回到原锚。Lootbar缺失沿原核心来源逻辑，不提升其他站为核心。原ItemD2R整体资格合同先复用，不能为获得单个平台价格擅自放宽其三平台、同run、时效与抓取跨度要求。

## 二、接入正常决策，保留原有能力

1. 同一套公式处理上涨和下跌，不先按“涨/跌”选权重。当前价是保持方案，不是上涨上限，也不作为加权市场输入；展示相对锚价修正与相对当前价变动两个数。
2. PS/Xbox各自同量计算后，以较低的市场候选形成共同基础候选，仍用共同成本池及两平台全目录下限核验；PC独立。保留两平台分别的来源贡献与分歧，不能对三平台混合平均。
3. 新的正常审核baseline使用加权市场候选，先与当前全目录成本/双红线下限取大，再沿现有分币向上取整、原尾价和目录复验逻辑处理。原纯锚的parity、hold以及Hermes自定义evaluate能力保留。不能只在页面显示权重、实际仍无解释地使用旧baseline。
4. ±1%指舍入/下限/尾价前的第二梯队修正预算。分别记录raw_weighted、成本下限后、分币处理后、尾价后及最终执行值。分币向上舍入误差小于1美分，原尾价可能产生额外偏移；如实标记，不能宣称最终价仍被硬限于锚价±1%。Hermes显式自定价继续遵守原“无隐式尾价调整”路径。
5. 原model_unavailable_fallback保持：模型无有效建议或建议拒绝时，使用原纯锚/当前价/成本下限公式及原尾价和全目录证明。不得悄悄将新权重引入失联兜底，也不因此取消已有正常降价与成本保本上调。它是已存在的明确例外，不与正常有有效建议的双向公式混写。
6. 第三梯队不能单独制造额外折扣。U4GM用于低价端价差及其变化，IGGM用于跟随/独立偏离线索；有独立证据支持时Hermes仍可评估不同候选。ItemD2R可能已整合其他站点，不额外给“多站一致”奖励，不让模型临时改权重。
7. v15未优惠及近七日真实优惠结构估算平均采购毛利均≥10%，覆盖全部实际交付/赠送、固定套餐、整数K自定义和舍入；不得改成最差单笔优惠10%。活动/热度仍仅观察，不加新价格系数。
8. 同轮输入、全目录核算、预览、策略身份与锁内CAS必须一致。新规则通过原版本机制可追溯；旧预览不能无声套用新权重。原ID、UNKNOWN、对账、ALL、缓存和公开读回全链路保持，不为验收制造强制变价。
