# 狂欢盛典扭蛋（累计消费档位券）验收场景

2026-11-17 整理，供主站开发实现「档位券领取」接口时对照，也是 FS 页面接入后的验收表。可执行版本：`releases/fs-dashboard/campaign-analytics-20261023/app/tests/carnival-capsule-scenarios.test.mjs`（参考模型 + 同一组场景）。

## 规则

- 累计实付 = 会员在活动期（北京 11/19 13:00 – 12/2 13:00）内**已付款**订单的实付金额合计，由主站 `/ajax/carnival/user` 的 `spend_amount` 返回。
- 档位与券（TempActivity 已配置）：$1→1501、$100→1503、$300→1505、$500→1507、$800→1509、$1000→1511，门槛含等于。
- 每次点击领取：发放「已达到且从未发过」的全部档位券，从低到高；已发过的档位不再发。
- 每个档位券每人只发一次（Admin `repeat_qty=1`），服务端必须保证并发点击也不会重复发。

## 待主站确认

1. 领取接口的地址、请求与返回（建议返回本次发放的券 ID 和会员券 ID 列表，以及已发档位）。
2. 退款、部分退款、取消订单后累计实付是否扣减；已发的档位券是否收回。
3. 测试账号的模拟累计金额：为内部测试提供一个只对白名单测试账号生效的金额覆盖，或在测试站完成真实付款，用来跑上表 1–10。
