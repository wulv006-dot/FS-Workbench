# FC27 改价总控制台与人工控制增量

状态：2026-10-30 待发布候选；代码、本地验证、正式 CI、合并、上线和自然周期分别验收。参考同日 RPG `/d4/` 实际页面的总开关、参数区和分组操作，不复用 RPG 的业务规则。

## 用户确认的行为

| 优先级 | 条件 | 本轮最终后台价 |
| --- | --- | --- |
| 1 | 人工干预开启 | 使用人工固定价；日常／冲额与临时涨幅均不参与生产选价 |
| 2 | 人工干预关闭、临时涨价开启 | 原经营策略选出的 X ×（1 + 自定义涨幅） |
| 3 | 两个开关均关闭 | 原经营策略价格 X |

固定价分别填写 Console（PS/Xbox 共价）与 PC 的 **USD/1K 后台单价**，最多四位小数；内部仍沿原 100K 基价和分币舍入合同。涨幅由用户填写，不自动反推活动折扣、不增加活动条件或结束时间。每轮先重新计算 X，再上浮一次，不按上轮已上涨的价复利。全局控制作用于各活动计划实际拥有的基础价资源，不越权改变另一计划资源。

人工干预不终止、重建或暂停原计划；关闭后继续原策略、原范围、原期限和周期，临时涨幅保留并按开关决定是否参与。系统总开关、自动运行和计划暂停仍分别沿原入口生效；已暂停／到期计划不会因保存新配置恢复。人工价依然保留原双20证明、成本、汇率、地区、赠币、后台与公开读回及原 Order writer 联动。
