# FC27 历史回放与每日影子

当前策略按可配置的自然间隔核算、执行。Hermes 每日一次根据前一日真实分时段经营、已确认价格曝光和两策略（日常运营/冲销售额）影子给出效果判断与建议；不逐轮审核，不自动切换策略。

## 历史入口与口径

FC27 页面“历史与复盘”可登记最近 7、14、28 个完整日或上一个完整自然月。以北京时间付款时间选单，开始日包含、结束日不包含；月度不表示本月截至今日。请求首次登记时冻结窗口，同一请求编号在跨日后仍指向原窗口。

任务沿现有 V3 队列读取原 Admin 合格付款档案、ES 商品身份和同单原生订单/优惠记录，不采竞品、不读取当前售价冒充历史价。汇总优先使用Admin对应原生范围能力；订单详情按具体接口已核日期与分页上限分段，已确认的28天限制仅适用于对应接口，不机械用于全部汇总；原档案缺日时，只有显式登记的历史任务才沿现有Admin/ES原生只读链补齐该段，不增加每小时采集。原缺日列表保留审计，另列仍未解决日期和补取来源哈希；真实返回零单才算零，缺档案不补零。原生商品身份不足仍为部分覆盖；失败保留已知部分，不用当前价或猜测商品填历史。原订单行和后来读取的版本保存在私有 `historical_inputs`，接口只展示聚合、覆盖、来源哈希和结果。重新读取的事实按实际可得时间记录，不能倒签为旧时点已知。

历史实绩重建展示去重后的美元净实付、数量覆盖和同单人民币采购毛利。缺历史汇率时不把人民币成本按当前汇率变成历史美元成本。Admin 人民币收入是读取时汇率展示快照，不能称原美元实际结算。退款修订链尚未由原档案读者完整提供，缺口明确记录；有已支付样本不代表退款净效应完整。

固定订单重算、需求反事实、旧策略回放只使用原时点可得的价格、成本、优惠和策略源码。旧策略以原决策快照created_at为可得时点，旧格式缺此字段时才取checked_at；不能把采集启动时间误作决策时间，也不把截止后来源自动移进历史。Hermes研究桥通过现有认证只读API按原快照回放，包含没有可执行quote的原无解快照；只返回算法结果和哈希，不返回私有输入。缺历史快照、条款或可识别实验时保留缺项，不能用后来补到的订单构造旧时点决策，也不能把情景预测当真实增量。

## 每日运行与恢复

每天 02:20 处理前一完整日。每日影子仅消费保存的快照，按 00–06、06–12、12–18、18–24 时段展示两策略（日常运营/冲销售额）结果。低谷和高峰由真实已付款订单确定，未覆盖时段不当作零订单。手动历史回放和每日影子使用独立消费进度，手动任务不会重新跑一轮两策略（日常运营/冲销售额）。

两者复用一个隔离的 oneshot 影子服务；没有常驻重启循环，不允许生产写价和外部采集。服务只读生产镜像、自有影子库可写。原请求先落账、再提交，结果按原编号核对；提交结果未知或原 worker 停止但未产生回执时保留故障，不重复启动。不同请求串行等待同一服务，不增加第二套调度。

Hermes 使用独立定价会话库、单线程队列及 provider 槽，读取已保存的每日资料。资料在提交前落账，模型不能因错误的报价编号重新计算两策略（日常运营/冲销售额）。模型失败保留原回执并告警，不阻断程序以后正常定价；生产计划明确暂停时仍保持暂停。

## 验证状态

本批包含付款窗口、跨日幂等、私有输入/公开聚合、独立进度、缺原结果、失败去重和 UNKNOWN 不重放检查。PR530正式CI的221项FC检查已通过，历史补齐及真实月度入口已完成，详见HISTORICAL-COVERAGE-20261027.md。每日跨日自然执行与长期收益仍分别验收，不由本次历史完成推断。
