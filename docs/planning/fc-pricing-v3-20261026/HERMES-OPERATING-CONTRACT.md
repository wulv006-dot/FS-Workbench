版本：2026-10-28 用户较低锚点修订。当前只启用 daily（日常运营）与 revenue_sprint（冲销售额）；本合同覆盖附件及旧五策略、礼包等值、中间竞争带和高价锚点接替的冲突要求。适用 Site266 / FC27 Game1327 / Gold / Server7645。源码、正式CI、发布、实际装载及经营效果分别验收。

## 运行分工

程序每60分钟采集并执行当前策略，间隔可配置；每轮只提交一套最终方案，基础价最多更新一次，必要地区系数各更新一次。正常周期不等待Hermes。拉新、积压、限时促销的计划入口、候选目标、日常采集和影子路径已退役；不把这些模式的缺数据变成当前任务前置条件。历史记录和冻结旧算法仅供审计。

Hermes每天一次，经独立定价存储、队列和模型通道复盘前一日真实分时段效果，说明预测、实际、参数和缺口，并建议下一步；本阶段不逐轮审核、不recommend候选、不自动切换、不写价。模型失败不阻断已授权程序，不额外占普通调查/报告会话。每日02:20使用保存输入运行两模式影子，不补采外站、不写价、不将模拟订单用于训练。

## 两种目标与参数

| 模式/参数 | 核算与使用条件 | 追踪方法 |
| --- | --- | --- |
| daily 日常运营 | 优化同范围总采购贡献；候选相对计划冻结锚点−8/−4/0/+4/+8%，不对上轮反复打折 | 比较实际净收入、已覆盖采购贡献、量价及预测偏差；贡献不是扣完广告和全部经营费用的净利润 |
| revenue_sprint 冲销售额 | 优化同范围净实付收入；有效锚点低5/6.25/7.5/8.75/10%，偏好低7.5%为次级排序；目标可空 | 保存采用锚点、相对每个竞品的真实价差、双20证明与实际订单表现；未达竞争目标不得标通过 |
| 自动间隔 | 当前默认60分钟，可配置正整数；恢复/修改时从实际时点重新排期 | 用统一调度回执的下一自然轮核对，不补跑暂停期间旧轮 |
| 结束时间 | 两模式均可留空，持续到主动结束/暂停；填写后按真实期限退出 | 不偷偷补7日/72小时/月末期限；既有计划原截止不因发布被延长 |
| 月净收入目标 | 同Site266/FC27 Coins/USD净实付；可留空，不编目标值 | 截至日、已核下界/区间、今日缺口分开；目标为空仍可做收入优化 |
| 对照/优选/探索 | 日常20/60/20%，冲额10/70/20%；六小时分配块合计1，只分配一次 | 重试不重新抽签；不是竞品权重，不产生多个并行生产价格 |

内部候选只是计算组合，不是逐个执行或客户试单。每轮只选一套方案；候选数量不等于写价次数。不引入定价预算、预占、耗尽暂停或机会成本硬限，实际折让/贡献保留为效果统计。

## 预测基数与核算条件

| 字段 | 来源与公式 | 缺口和验证 |
| --- | --- | --- |
| orders_per_block | 同网站/游戏/Coins/价格组真实付费单数 ÷ 实际覆盖小时 × 6；七完整日为168小时 | 记录窗口、样本和观察时间；无绝对基数时只给相对指数，不补零 |
| target_revenue_per_order_usd | 同批净实付USD ÷ 付费订单数；净AOV已经包含实际优惠 | 不重复扣优惠，不将原币实付直接当USD，不把100K商品价当真实AOV |
| purchase_k / bonus_k / delivered_k | 原生商品行购买K、历史赠送K和行倍率；交付K=购买K+赠送K | 多商品行逐行核算，历史不套今天赠送规则；无法识别保留缺项 |
| delivered_k_per_order | 同批全部含赠交付K ÷ 同批订单数 | 不能将每单固定成100K或105K；与需求/采购成本使用同一群体 |
| reference_regular_usd | 实际平台/地区/数量一致的已核价格基准 | 历史映射到当前价格属于明确冷启动假设；不冒充当前公开价 |
| retained_ratio | 最近七完整日同批净实付 N ÷ (N + 实际ES优惠金额 D)，按金额加权 | 来源、群体、窗口和hash一致；付款状态变更沿原生Admin会计/ES重建同一窗口，采集与写前核同一份已对账基数；档案再变化则重建，不能静默跳过 |
| cost / FX | 当前Order有效平台采购成本CNY/K及同版本CNY/USD；PS/Xbox共同池，PC独立 | 原记录身份、时点和单位齐全；成本覆盖全部赠送，不能用旧成本绕冲突 |
| elasticity | 初始中心2，0.5/1/2/4敏感性；Q(p)=Q0×(p/p0)^(-ε) | 初始假设不是拟合事实；只用合格真实曝光/订单/退款/迟到成本更新，影子不进训练 |

预测收入按真实净AOV及可比价格比例推算；采购成本按预测订单×每单含赠K×有效单位成本。不把预测收益称已实现增收。客户身份、广告和履约可用于复盘背景，不能重新成为已退役模式的自动采集或阻断项。新客按当时原始标记/已核邮箱口径，UID=0不排除也不自动算新客。

## 财务、竞品和地区

两条硬线共用原完整算法：未优惠实际采购毛利≥20%；最近七完整日真实优惠金额结构下估算平均采购毛利≥20%。覆盖全部套餐、赠送、整数K自定义、地区及金额舍入；合法单笔优惠仍可低毛利或亏损。Hermes、人工、恢复和地区系数不能豁免。

全球用Lootbar无券；冲额同轮使用ItemD2R。ItemD2R按原始100K金币核算，不参照Lootbar增加礼包金币等值，不使用user_lootbar_same_tier_v1。各来源分别保留购买K、真实金币赠送K、原金额、交付方式和时间；有效单价为USD总价÷实际交付K。原始礼包宣传不变成金币交付或训练标签。
