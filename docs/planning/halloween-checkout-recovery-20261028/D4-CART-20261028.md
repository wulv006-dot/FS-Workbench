The Spark page already applies its10% product discount to the $7.49 unit amount. Its input exposes `data-price=7.49`, `data-discount=90`,quantity1. The D4 script `https://www.mmoexp.com/mmoexp-v250528/js/goods/item-d4.min.js?1793159575` calls `js_rate(unit * quantity, rate, discount)`; the shared `start.min.js` divides the discount by100, multiplies, then uses `js_number_format`/`Number.toFixed(2)`. Thus the activity reference must be $6.74 before its event discount; using unit_price alone incorrectly shows $6.74 after a10% event discount instead of the native $6.07. Payment fees remain native-cart data, not part of the activity reference.
