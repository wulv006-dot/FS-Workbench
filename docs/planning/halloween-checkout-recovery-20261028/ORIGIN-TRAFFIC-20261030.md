# 187-side document-request estimate

User scope: reuse existing187 access logs for rough activity traffic; do not depend on a Cloudflare account, create client identifiers, collect behavior without consent, export raw IP, change prices/coupons or pay for services.

The existing authenticated FS service adds `GET analytics/api/origin-traffic`. It accepts only activity `mmoexp-seasonal` plus strict inclusive UTC `from`/`to` dates (maximum31days, no future-only range); `refresh=1` bypasses its10minute cache. No client-controlled file paths. Existing loopback/authentication and read/write policy remain; no PostHog credential is required for this independent read.

Only existing `/var/log/nginx/access.log` and sequential numbered rotations, including gzip, are read. Count exact `/events/seasonal/index.html` and `/events/seasonal/` GET200 records; exclude assets, API, HEAD, known bot/automation UA patterns and `analytics_test=1`. Refreshes count again. Unrecognized bots, internal tests, prefetch or proxy retries can remain. These are origin document requests, not people or a full browser/edge PV count. Requests served without reaching187 can be absent.

Streaming bounds: at most8physical log files,32MiB compressed/raw and decompressed per file,64MiB total decompressed,16KiB per record and10seconds per scan. Concurrent source reads serialize within this reader; unrelated API reads do not share that queue. Eight date-range cache entries maximum; failures have5second cache, regular results10minutes. Current inode replacement/truncation invalidates the cache. No timer, new log, archive, security permission, credential or billable service is added.

Physical aliases and full byte-identical copied logs are counted once. Ambiguous overlapping time ranges, missing numbered rotations, incomplete records, unknown formats, read errors and limits cannot return a complete-period number. Available range: `pageRequests` is the request estimate. Partial history: `pageRequests:null`, with separately labeled `observedPageRequests`/daily numbers only for read logs. Unavailable source: both null. A real fully covered range with no matching requests may return0. UTC date totals can be summed for request volume; no IP/visitor aggregation is performed. Full-period coverage is determined from the actual readable file timestamps, not assumed from the selected filter.

Only day counts, coverage timestamps, file/byte counts, status and aggregate exclusions are returned or cached. No raw log row, IP, UA, query value, cookie, identifier or source path is returned to the browser. In-memory file content digest is used solely to detect exact copied log files; no persistent client identity. Existing raw logs are neither copied nor retained by this feature. `estimatedVisitors` remains null with `UNVERIFIED_PROXY_CHAIN`; source XFF presence alone is insufficient.

The FS panel independently loads the request summary, so PostHog failure does not erase it. It explicitly says all games/devices/channels, shows UTC selection and BJT coverage time, distinguishes partial/missing from0, suppresses the query in test mode, and leaves behavior UV and paid-code revenue unchanged. Report context points to a separate source query rather than calling the full edge layer connected.

Validation uses temporary synthetic common-log fixtures and isolated browsers: UTC boundaries, exact path/method/status and UA/test filters, repeated refreshes, zero versus missing, symlinks, gzip, rotation aliases/overlap/gap, byte limits, incomplete rows, cache TTL/forced refresh/inode replacement, concurrent date ranges, authenticated endpoint validation, partial/error UI and PostHog independence, and existing4viewport/theme and purchase-report checks. No production event, draw, cart, purchase or payment is generated.

Release targets only analytics/origin-traffic.mjs, analytics/production-server.mjs, analytics/dashboard.js and analytics/report-context.mjs via the original publisher, unchanged required gateway/service baselines and original shared locks. No public static-manifest entry corresponds to these backend/operator files; do not regenerate unrelated public assets. Current publication, private price policy, coupons, runtime environment, registry and other module sources are preserved. Source code, CI, independent review, actual deployment and real-browser readback remain separate evidence stages.
