# 用户分析怎么用

**只选开始日期，结束自动到昨天；只看这段期间买过的邮箱，之后有没有再买、截至昨天处于什么阶段。** 一个确认邮箱算一人，游客订单也计入。

[打开正式用户分析](https://47.85.224.112/dashboard/users/)。期间版已上线，本轮等待用户验收，实际状态以[交付记录](DELIVERY.md)为准。

## 最常用的三步

1. **选范围和开始日。** 看整体选“全部”，看某游戏选“具体项目”。不用选结束日期：今天10月23日，就固定统计到10月22日。
2. **看这批客户的购买。** 先看期间购买人数、后台标记新客/老客/待核，再看已复购、未复购和期间复购率。
3. **看阶段，再细分。** 点沉默或流失等阶段，下面可以选“已复购/未复购”，再交叉选“新客/老客/待核”；打开个别客户时间线核对。

切换筛选后点“查询”。首次查询较长期间可能需要几十秒；看到“正在读取”时等它完成。名单、导出、时间线和交给Hermes的结果来自同一份快照；刷新后得到的新快照与旧版分开保留。

## 看不懂字段时

卡片、主要筛选和表头旁的 **?** 是说明入口：鼠标移上去、键盘选中或手机点击都可以打开；按 Esc 或点外面关闭。阶段说明会显示当前规则的具体天数。新老客标记“待核”只表示标签不明确，这些客户仍包含在购买总人数中。

阶段细分表同时显示人数和占本批购买客户的比例。右边“期间已复购／期间未复购”的人数可以点击继续核对；同一人截至昨天只占一个阶段，但期间可能经历多次变化。

## 直接查一个邮箱

1. 先选开始日与范围，点“查询”。“数据范围”会写出真正生效的日期、项目和阶段规则；条件改了但还没查询时，会有提醒。
2. 在上方“按邮箱查购买记录”输入完整客户邮箱，点“查这个客户”。只有管理员能用。
3. 弹窗会列出该邮箱在当前期间及范围内的全部已记录订单和时间线，包括付款时间、项目、原状态、是否计入有效购买、整单美元金额，以及复购、沉默或回流经过。其他状态订单供核对，不算有效复购。

例如想核对某客户7月以后在FC的购买，选7月1日和FC范围再查邮箱；想看他跨游戏的全部购买，先切回“全部”并查询。同一份快照下，搜索和从名单展开的内容一致。

邮箱需完整匹配，只忽略首尾空格；保留大小写、加号和点号，避免把两个人误并。未找到时只说明“当前期间及范围未找到有效购买客户”，不代表此人从未买过。搜索不会自动扩展日期或去后台拉多年历史。

## 人数与复购怎么理解

| 页面上的话 | 日常说法 |
|---|---|
| 期间购买客户 | 从开始日到昨天至少有一笔有效订单的邮箱；买十单也只算一人 |
| 期间首单D0 | 这个邮箱在所选期间的第一笔有效购买；不代表他有史以来第一次买 |
| 后台标记新客/老客 | 看期间第一笔有效订单原来的ES“是否新客户”标记；不需要为此追溯多年历史 |
| 标记待核 | 首单标签缺失、没有匹配到，或出现冲突；不默认算老客 |
| 已复购 | 期间有至少两笔不同的有效订单；一单多商品不能算两次 |
| 未复购 | 期间只有一笔有效订单；还要看过去多久，不能直接说流失 |
| 期间复购率 | 期间已复购的邮箱数 ÷ 期间购买邮箱总数 |
| 快照 | 把这次查询固定下来的一份结果，方便页面、名单和Hermes对数 |

例如期间100人购买，其中30人至少买了两笔，期间复购率就是30%。这是所选期间的购买行为；不是终身复购率，也不能用订单数相除。

如果同一人7月买过、10月只买一单，选择10月开始时，他可能是“后台老客、期间未复购”；7月的购买不会混进10月的复购次数。改开始日期后，期间D0和这批客户人数可以变化。

## 截至昨天属于哪个阶段

阶段按**这段期间的末次有效购买，距昨天的北京时间自然日数**计算。

| 规则 | 还没到沉默 | 沉默期 | 流失期 | 长期流失 |
|---|---|---|---|---|
| 统一30/60/90天 | 不满30天 | 满30、不满60天 | 满60、不满90天 | 满90天 |
| FC14/30/90天 | 不满14天 | 满14、不满30天 | 满30、不满90天 | 满90天 |

如果只选最近30天、采用统一30天规则，沉默和流失可能为0，因为这批人都在近30天买过；要看更久未买的人，往前选择开始日。

还没到沉默的人再分两组：期间只买一笔的是“待观察”；期间已经复购的是“已复购且近期购买”。其他阶段也能继续拆成“只买一次后没再买”与“复购后又停下”。

“流失”只是按停买天数划分，不代表永远不会回来。再次购买可称唤醒或回流；订单本身不能证明是某次营销、优惠或客服动作带来的。

页面还有固定7天/30天复购：从期间D0起，看固定天数内是否再买。已经完整走完这段天数的人才进入分母，刚买两天的人先单列观察。它与上面的沉默天数各算各的，也不只针对后台新客。

## 五个使用情景

以下人物和人数全部为**虚构示例**，只演示读法。

### 1. 看7月以来的客户后来怎么样

选开始日7月1日，结束自动到昨天。先看购买人数与期间复购率，再看待观察、近期购买、沉默和流失。此前只在6月买过、期间没有买的人不会混进来；今天新买的人要等明天的完整日数据。

### 2. 同样沉默，谁只买过一次，谁复购后又停下

按统一规则、观察日10月22日：小李9月1日只有一单；小王7月有订单、9月1日再次购买，之后也没买。两人都在沉默期，但一个未复购，一个复购后沉睡。

点“沉默期”，选“未复购”或“已复购”分别看，再打开时间线。不能只用总沉默人数把两类人当成同一种情况。

### 3. 刚买的人还没复购，是不是流失了

小陈10月20日买了一单，到22日才过两天，还没达到沉默规则，应在“待观察”。小赵20日买一单、22日又买一单，则是“已复购且近期购买”。

先给观察时间，不把刚进来的人直接归到沉睡或流失。

### 4. 新客和老客的表现是否不同

点“后台标记新客”或“后台标记老客”卡片，查看这一组的阶段和是否复购；也可以先点流失期，再在名单里交叉筛选新老客与已复购/未复购。

这里的新老客取各邮箱期间第一笔有效订单的原标记。标签待核的人单列，不因为没有更早历史就全部归为新客，也不因为是游客就当新客。

### 5. 让Hermes帮我解释

查询后，在下方选择一个已有持续会话，点“交给Hermes分析”。提交成功只表示开始处理，到持续对话里看最终报告。

可以继续问：

> 用这份快照解释：这批客户有多少人复购，未复购中哪些仍待观察，沉默和流失里哪些曾复购后又停下。新老客用期间第一单的后台标记。区分订单事实、可能原因和待验证结果，不联系客户、发券或改价。

让Hermes写出快照编号。以后复查要重新查询，旧快照不会自动长出新订单。
