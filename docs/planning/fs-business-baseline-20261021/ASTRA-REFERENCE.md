## 1. 先定义钱和数量

- `Qb` 为购买 K，`Qg` 为赠送 K，实际交付 `Qd=Qb+Qg`。
- `c` 为合格最新订单发货成本 CNY/K，`f` 为有效实际 CNY/USD，当前报价交付成本 `C=c×Qd/f`。
- `P` 为实际展示套餐总价，原引擎采购毛利 `G=P−C`、毛利率 `m=G/P`。
- `R(P,z)` 为指定资格、优惠及已核收入定义下的收入情景，经济评估用 `R−C`。已扣优惠不得再扣，库存中已统一的流量/使用费不得重复添加。

原引擎10%底线照旧。优惠后经济评估是补充检查，不能声称引擎已逐单保护优惠后利润，也不能暗中改底线。缺完整费用时不称净利润，未验证未来客户价值不抵当前损失。主指标为同窗采购毛利总额，辅看完成订单、实际交付 K、退款/问题及成熟复购。

竞品用满足同等资格和交付条件的实际应付USD/实际交付K。当前引擎以竞品交付单价乘100购买K生成锚价，自家赠送另计成本；其返回降幅不等于双方实际交付单价差，两者分开。

## 2. 四档的真实算法与局限

| 原档位 | 代码实际选值 | 局限 |

| >=40% | 参考竞品差距均值先最多取10%，再夹到2.5%–5% | 无正向价差时也可能被最低2.5%强制让利 |

| 20%–30% | 先取5%，再夹到0%–1% | 有参考源时通常直接取上限1% |
| <20% | 取0 | 利润空间与需求机会未分开 |

## 3. 推荐决策顺序

1. 核平台、购买/交付K、成本、FX、前台和时效。原核心来源顺序保持，Lootbar必须有效；核心缺失停止新增报价，其他部分仍可解释。
2. 在同一冻结输入列实际当前价、原策略计算价、研究候选价，不能都称原价。
3. 当前已满足成本和既定竞争定位、缺少价格流失证据时优先保持；有持续可比竞争差距才研究消除必要差距的最小降幅；竞品低于保护价或优惠后损失未清时明确不可跟或条件未清。
4. 计算候选需要多少额外销量才能补回毛利：`u_BE=G0/G1−1`，仅在两者正值、成本/套餐/结构可比时成立。这是盈亏平衡门槛，不是预测。套餐、赠送或优惠结构变化时分情景重算。
5. 收益依据和全部保护通过后才提交原审核/执行链。本次不执行。

现有共享四档可比较原策略、取消强制最低让利的候选及有明确竞争依据的候选。连续优化、平台独立规则、优惠联动、需求预测和迟滞状态机仍属待实现；改四档数值不能冒称已经实现它们。突破旧降幅必须解释必要价差、毛利代价及需验证的需求增量。

## 4. 触发、迟滞、撤回

安全条件立即生效：成本/资格失效、破原底线、平台联动失败、UNKNOWN未结等停止新增相关动作；“保持旧价”不证明旧价安全。

普通竞争差距可研究连续两个有效自然周期同向后再处理；**两个周期是未校准研究起点**，120分钟周期不改。进入阈值大于退出阈值，按历史噪声、最小有效参数变化和可承受毛利损失选择；目前没有最佳百分比证据。

真实实施后未达预定毛利结果或退款/履约恶化时结束候选。撤回按当时成本和前台重检，不能把历史价当天然安全回滚。用户OFF保持，UNKNOWN按原ID对账，不重放。

## 6. 为什么优惠汇总不能识别机制

同窗原ES结构分别能计算折扣对整单金额结构比、新客标记单均优惠和该组优惠金额份额；具体经营原值与计算回执留在FS及受控本机材料，不进入代码文档/Notion。不能据这三种汇总识别固定优惠、核销率、退款后净额或增量获客。

多数新客订单接近30%也不能排除订单结构。虚构反例：90笔小额单各基数10美元、优惠30%，另10笔大额单各1000美元、资格不同无优惠；90%订单享30%，整体金额优惠比仍只有270/10900约2.48%。数量多数不等于金额多数。

保留四类竞争解释：比例优惠但资格覆盖不同；固定/封顶/满减；客单和商品组合变化；退款/状态/记录口径差异。需要同订单关联的基数、实际USD优惠、资格、机制、数量、状态及退款处理，在可比子群比较优惠额随基数变化。边际汇总不能拼联合分布；工具缺项则提出最小有界样本需求，保留解释。机制查清仍不等于增量效果。[Google GA4优惠记录](https://developers.google.com/analytics/devguides/collection/ga4/apply-discount?client_type=gtm&hl=en)也区分码与实际折扣，但事件定义不替代本项目后台合同。

## 7. 数据升级和最小证伪

| 升级判断 | 最少补充 | 可以证明 |
|---|---|---|
| 当前可跟价 | 有效平台成本/FX、真实前台、可比资格/交付条件 | 候选算价可用 |
| 哪档值得降 | 套餐数量/商品行、实际优惠、订单/发货关联 | 情景毛利风险 |
| 优惠机制 | 同单基数、资格、机制、状态 | 解释的适用范围 |
| 降价能否增利 | 真实价格暴露、执行时刻、可比对照、完整结果窗 | 候选因果效果 |
| 新客长期价值 | 已核身份、成熟同批复购及利润 | 有边界价值估计 |
