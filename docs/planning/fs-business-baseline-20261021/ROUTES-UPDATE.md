# 折扣码筛选与指定订单日志补充

2026-10-21，用户文字及所附Admin截图为本次口径来源。生效正文见[业务基准第2、7、10节](BUSINESS-BASELINE.md)，版本v3，保留v2尾价及利润/反证澄清。

- 真实浏览器核到 `/admin/market/discount` 搜索按钮展开码、推广人UID、站点、应用游戏、有效起止及统计时间。按用户限定只统计MMOEXP；有效期与统计窗口分别记录。
- Total Sales、Total Sum、Total Used分别保留。Sum是码关联消费，不是优惠金额；Used与Sales不能互换。所含订单状态、退款处理及统计采用的实际时间字段尚未独立核全。
- 复用同窗口ES下载核单号与原状态，异常再查 `/admin/orderes/orderlog` 或Order详情日志。Admin日志真实页面显示订单号、状态、备注、操作人及日志时间；未读取指定订单全量日志，不宣称与Order覆盖完全相同。
- 这是现有知识装配链的文本基准修订。未新增伪工具或爬虫，未修改UI、采价周期、登录、自动化、售价或利润底线。后台可用与Hermes当前可调用工具严格区分。
