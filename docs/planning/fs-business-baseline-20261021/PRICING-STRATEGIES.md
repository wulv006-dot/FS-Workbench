# 两套 FC 定价策略｜通俗对照

2026-10-21。本Work的策略和Hermes自行修订的策略分别保存，后者没有被施工者改写。两套都是供人工判断的条件式方案，没有执行改价、实验或新的自动规则。

| | 我的策略 | Hermes 的策略 |
|---|---|---|
| 一句话 | **算清实际成本，只做有理由、能留下更多钱的必要调整。** | **以总采购毛利为目标，单均毛利作护栏；先补齐比较条件，再研究跟价。** |
| 当前怎么做 | 竞品条件不齐时不报新商业售价；成本安全另查，不能默认旧价安全 | 不做统一调价，也不因标价线索预先选某平台降价；核订单日志判断履约风险 |
| 为什么降 | 确有可比竞争/转化压力，且有条件补回让利损失 | 补齐后确实更贵，原护栏通过，保本销量增量和承接能力还需验证 |
| 降多少 | 比较保留、小调和更大调整，优先选能解决问题的较小让利；没有需求证据不拍最佳幅度 | 以真实可比价差和到底线的空间约束候选幅度；不编固定窄带 |
| 钱怎么看 | 采购毛利、广告后贡献、经营参考利润分三本账；有归属数据时重视广告后留下的总额 | 主目标明确为总采购毛利，广告后贡献另行评估投放是否值得；不重复扣广告 |
| 怎样改变判断 | 候选不能带来足够同口径额外贡献、数据口径失效或履约恶化时重新评估 | 完整报价改变排序、成本触底、同账龄日志证实积压、归属广告或收入定义改变时重选分支 |

我的侧重点是实际经营取舍和最小必要调整；Hermes 的侧重点是把证据补齐、优化总额与单均护栏分开。两者目前都缺少可靠的需求响应证据，不能据此宣称具体降幅最优或利润一定提高。

共同执行顺序是：**核成本和交付量 → 核同条件竞品与实际现价 → 比主候选 → 算保本增量及广告后贡献 → 逐平台过保护 → 最后检查 .99 → 按证据决定是否提交原执行链。** 本次止于只读研究，没有提交新的生产策略。

.99 只控制主候选之后的额外让利，四项预算同时满足；主策略研究可突破旧降幅，原底线、PS/Xbox 联动、周期、开关和售卖链不变。赠送计成本，优惠不重复扣；未闭观察窗、相关性和模型自评都不替代收益证据。
