- 普通版：三页Player候选均按当次PlayersType事实筛选normal；Signature和类型未知不混入。跨卡系列仍允许。
- SBC覆盖：第9个核心 `44714235` 位于目录第2页，仅取首屏会漏项。沿原分页读取最新9个核心；Sol各配2名普通Player，全局18人去重，应用层为每核心保存2首选＋其余16共享备选。
