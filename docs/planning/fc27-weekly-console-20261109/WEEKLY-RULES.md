- 自动更新：每周日12:00，Asia/Shanghai（北京时间，UTC+8）。管理台可手动触发同一条取品/候选流程，也可自动或手动刷新已有状态；状态刷新不派发模型。
- 用户已明确允许Hermes使用本人身份，并授权验收时真实使用模型进行页面商品更新测试。人工请求验证当前FS会话；自动任务须由该会话登记可撤销的限定范围委派，不持久Cookie、不接受客户端任意owner、不冒用旧报告身份。

- 不发送社区消息，不干扰主站结账、FC定价P0链路或已有模型任务。原ID未知不换ID重派。
