## 1. 先把成本和利润算对

候选成本用对应平台最新有效订单交货成本 CNY/K，乘购买加赠送的实际交付 K，再按有效时点的 CNY/USD 换算。历史实际利润使用原订单成本及原记录，不能拿今天的成本或汇率重算过去。

价格管理中的“采购成本、利润率、6.65”是售价公式参数，不能当真实经营成本。金币正常计成本；用户已说明统一计入自家库存的流量及系统使用费不重复加。补发属于经济成本，但已接 Order 发货并不保证涵盖所有补发，要标明缺口。

采购毛利＝对应订单净收－对应交付成本。广告后贡献＝同范围采购毛利－同范围广告费。二者都不冒称完整净利润。退款、未完成、未知成本分别处理；同单收入只计一次，重复发货累加对应成本，已净扣的优惠不能再扣。

现有桥接返回 USD 订单及折扣、CNY 覆盖完成单的销售/成本/毛利。没有逐单历史换汇与同范围 Ads，不能直接跨币种相减算广告后贡献。

## 2. 保持、降价、涨价都列候选

| 方向 | 判断依据 |
|---|---|
| 保持 | 已达到目标竞争位置，没有支持变价的新证据，避免仅因毛利高机械再降 |
| 降价 | 有同条件竞争差距或有效需求证据，先算至少要多卖多少才能补回让利 |
| 涨价 | 成本挤压利润，或存在可核实的上调空间，先算最多能少卖多少 |
| 证据不全 | 给条件方案和待核项，不把研究缺口变成新的生产停机规则 |

候选至少包括当前实际价、达到已核竞争位置所需的最小变动；更大幅度要有需求假设和收益依据。可以突破旧毛利四档降幅研究，但不能“毛利高就降到上限”。旧四档是毛利对应降幅，不是竞争价差档。

竞品必须核优惠资格、必付费用、交付方式及有效期。只看到展示价时，不能宣布真实最低价或具体跟价目标。

## 3. 每个候选算保本量，不把它当销量预测

在平台、套餐、优惠和订单结构可比时，原每单毛利 g₀、候选每单毛利 g₁、原订单量 Q₀：

`保本订单量 Q₁＝Q₀×g₀/g₁`

若广告投入变化：`Q₁＝[Q₀×g₀＋(A₁－A₀)]/g₁`，要求 g₁＞0。

降价报告所需增量，涨价报告可承受损失。分组算后汇总，不能把平台、面额、客户结构变化误当价格效果。保本量只是条件计算，不是需求弹性、销量预测或增利证明。现有套餐 K 缺失时不声称完成逐档效果评价。

先得到主候选价 P₁，再尝试 `T＝floor(P₁)－0.01`；已经 .99 则保持。附加让利预算沿已确认公式：

`B＝max(0,min(1%P₁,5%(P₁－C),P₁－C/(C/P₁＋0.01),P₁－C/(1－m)))`

只在 P₁−T 不超预算且最终交易满足底线时采用。共同价格按合法客户成交/优惠组合检查；有券折扣时另算折后净收与真实毛利。1%只限制尾价的附加让利，不是主策略降幅上限。这是受控偏好，不能凭空计入转化收益。

## 5. 用原周期和反证验方案

复用原120分钟自然周期，关联执行状态、后台参数、独立公开价格暴露、订单、成本、退款和营销。执行账本后台 before/after 不替代公开暴露，前后销量变化不证明价格因果。

新策略的迟滞阈值和确认周期应按历史报价噪声与操作成本校准，先只读回放，不凭空设为现行阈值。回退候选也按当时成本重算，不能机械恢复旧价。生产执行仍走原授权、锁、CAS、UNKNOWN和回退机制。

三个必须推翻错误结论的情形：

- 已经便宜，仅因高毛利再降：需要证明额外销量值得毛利代价，竞品条件不等价时撤回“已占优”的判断。
- 共同成本来源记录不一致或某合法客户成交组合不足：先核实来源/优惠资格，再评共同候选；不把历史压力测试的不同平台成本套回真实业务。
- 订单增长同时广告加投、退款未成熟：不归功于降价；成熟贡献未达保本或对照失效时撤回增利判断。
