## 当时的验收清单（已退役）

1. 从正式群的无球队身份普通成员视角，确认 Matchday、Match Chat、FC27 Welcome、Players、Coins 均可发现，Matchday 只读而 Match Chat 可发言；手机端复查相同路径。
2. 选择一场实际即将开赛的焦点赛，先核对 Smart Score 赛事名称、联赛、开球时间与来源，再在正式 `fc27-matchday` 开启一场订阅；订阅状态要用应用自身命令读回。2026-11-15 00:12（上海时间）查询时该频道仍显示无直播订阅；此后桌面 UI 切换到测试群，后续命令是否提交未得到回执，不能猜作成功或失败。
3. 记录 Smart Score 开球、进球/更正、半场、完场卡与 FC Chat Assistant 对应讨论卡的消息 ID、实际时间、来源链接、去重结果；分别计算“赛事事实 → Smart Score”和“Smart Score → MMOEXP”延迟。前者没有独立赛事时间戳时保持未知。
4. 验证公开消息从赛事频道可以进入同一场讨论，再由讨论进入 FC27 阵容/球员内容；商品报价须由玩家主动点击，价格仅本人可见。当前只实现讨论卡返回赛事卡，反向入口尚待补。
5. 当用户自然产生服务需求时，验证 Players/Coins 报价、网站跳转和私密客服入口；只记录必要的聚合指标，不能把聊天文本当购买意向画像。
