## 策略判断与使用边界

当前两段定价、只比较竞品 100K、按 D-8 至 D-2 同单金额加权优惠的组合，符合用户要求的动态调整与简化计算。1000K 以上以同段单价联动并保留比例赠送；较小订单和大额订单分别观察，不用竞品大单报价推动大额段。18% 是本模型的组合采购毛利底线，25% 是目标，不能将每个时段未达25%都视为失败，也不能把采购毛利称为净利润。

主要经营取舍是平均优惠对促销突变有滞后、短期分段样本可能不足。沿现有自然轮修正，重点比较完整日的收入、利润与利润率；未成熟的24/72小时样本不作因果结论。本轮补充有限的2%/1%候选属于漏选修复，不扩大采集，不逐分钱搜索，不更改目标或底线。
