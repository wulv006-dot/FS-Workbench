## 已直接核对的行为

| 输入动作 | 当前脚本行为 | 边界 |
| --- | --- | --- |
| 单位价 change | `je → W → oe`，所有现有 price 行按 unit_price × gold × discount/100 重算，再 `Number(toFixed(2))` | 不自动修改 give；遍历长度取 price 数组 |
| 单档 gold blur | `qe` 仅重算该档价格 | 未证明客户自定义数量约束 |
| 单档 discount change | `Je` 归一该折扣，复制给全部后续档位，再重算全曲线 | 不是单档独立改动；UI min .01/max 100/precision 2 不等于服务端校验 |
| 单档 price change | `Ke`：与现公式差小于 .005 则不处理；否则反算折扣，传播到后续档位并重算全曲线 | 分母为零直接返回；反算折扣保留两位 |
| 参考总额/数量换算 | `ge` 单位价保留8位再重算全曲线 | 函数已读取，未证明其全部界面触发入口 |

折扣归一函数：非有限数回到100；两位小数结果在 (100,100.05] 时收回100。上述只是当前原文行为，不应擅自作为新业务规则或新的生产兜底。
