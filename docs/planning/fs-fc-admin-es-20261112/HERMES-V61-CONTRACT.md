- 写前按同一优惠窗复核日期、归档修订和平台金额，证据变化先重新采价，跨日旧证明不可写入。
- 本平台平均优惠率＝同范围去重原订单的 ES 实际优惠金额 USD 总额 ÷ 同单优惠前商品金额 USD 总额；留存比例＝1−平均优惠率。按金额加权，不按每日率或订单百分比等权，不借用其他平台比例。
- 优惠前商品金额取已核 Admin 商品金额字段；不能把包含支付附加层的客户实付差额当优惠。绑定共享 ES 固定版本、订单身份、日期、平台和原始修订。缺少必要金额或身份时保留缺口，不补零。
- 当前与候选曲线按本平台留存比例估算净收入。`pricing_assumption`、`domain.version` 和 `average_discount` 采用本合同版本；`receipt_status=forecast_under_average_discount` 明示经营估算，不冒充逐单实收。
- 用户要求不再逐券、会员、积分、混单精算：这些路径未逐一证明不再单独阻塞本方案激活；保留已有明细供分析。合法单笔优惠仍可低毛利或亏损，不能把平均假设的通过说成极端优惠组合必然保本。

未启用 `margin_band` 的市场锚计划仍评估阶段 4 定位溢价 p。上周 p 提高1个百分点时，若本段订单≥前周×M×.92且采购毛利额≥前周×M则保留；否则退回1个百分点并冻结本段两周。上周未抬 p 且平台订单<前周×M×.85，则先小额降2个百分点；否则小额、大额轮流提高1个百分点。每平台每周最多调整一个段，受 p 范围、冻结、U7Buy封顶及财务底线约束。

提议带两周来源版本、命中规则和原计划修订，只能由计划所有者确认、拒绝或自然到期；周三24时仍未确认则本周不调整。前四周从首个有效提议起算，逐项人工确认；满28天后仍由吴律明确开启自动，未开启继续人工。确认只走原计划 CAS 修订，下一自然轮重取证明并沿原 writer 执行；KEEP确认不制造修订。Hermes沿 `pricing_review_v3` 原入口接收提议，不增设平行定时器或恢复已暂停报告。
