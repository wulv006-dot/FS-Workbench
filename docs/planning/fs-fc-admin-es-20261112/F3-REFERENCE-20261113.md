# FC27 V6 固定基线与原操作采用

V6 候选将每个平台的已采用 site266 完整价表 A、当前比较周期及最初价表存入原定价账本。首次建立需要内部调用方提供已确认的完整读回、证据引用和采用理由。比较口径变化可按原周期 ID 开启新周期并继承 A。只读预览可显示已保存的 A 和两个版本 ID，当前 Admin 读回仍单独显示。
