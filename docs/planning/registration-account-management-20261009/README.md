# 账号审批与登录反馈增量

本次仅实现新注册账号的批量批准全局只读、拒绝、撤销，以及登录失败的可见反馈。管理员入口：`/__auth/access/`。基于2026-10-09真实SHA核对的当前前端，仅三个前端文件为拟发布载荷；原冻结runtime、DB、检查点、Nginx、systemd、认证合同不修改。

## 使用

管理员登录后进入“账号与权限管理”，勾选当前页账号、填写审批原因，再选择批量动作。确认窗列出人数、账号与原因。待审批和已批准账号分别处理；每页最多50条，下一页不会继承选择。逐账号复用原CSRF、申请版本CAS和审批审计。失败分项显示，401/403/429停止；网络中断、异常响应或5xx视为结果待核对，停止其余操作，不自动重放。先刷新并查审计，再决定是否继续。

现有平台账号与申请账号输入错误密码时，在对应表单按钮上方显示“账号或密码错误，请检查后重试。”并滚动到可见位置；失败保留输入、恢复按钮。无账号存在性提示，也不改变服务端认证或频率限制。
