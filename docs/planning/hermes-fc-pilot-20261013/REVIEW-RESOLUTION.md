# PR108 数字与幂等审查处置

合并前读取自动审查，确认两项 P1 与一项 P2 均有效。原101项绿灯不能替代这些检查，因此未合并/上线。

- 报告数字：新增 number_claims，按报告字段绑定实际证据的 JSON-pointer，逐数字核值与显示精度；支持小数/千分格式，明确比例字段可转百分数。真实证据的已知金额10.00不能支持999.00。原始数字仍能写进报告，无固定发现条数；因果/行动质量仍需业务验收。
- 计算输入：每个操作数必须由 value_paths 解析真实不可变证据并相等；额外输入仅在 assumptions 中明确声明，并把整项结果标为情景。情景数字不能出现在事实结论里作为已观测结果；无需完美订单对账，但不能把输入假设“洗成”后台事实。
- 语义幂等：template fingerprint 排除运输用 request_id。同所有者、同快照和相同问题/模式重新提交时返回原 task/run/结果，用量仍一次；ALIASED 请求只指向规范请求，不移除原活动任务的代理，也不创建新 Run。

本机103项通过，含错误金额、无绑定数字、错误计算操作数、情景冒充事实及不同request_id重试的回归。最后head/正式CI/合并/生产阶段状态以 runtime-progress.json 与后续实际读回为准。未把自动审查文字当作新业务口径，未调用真实模型或重放旧日报。
