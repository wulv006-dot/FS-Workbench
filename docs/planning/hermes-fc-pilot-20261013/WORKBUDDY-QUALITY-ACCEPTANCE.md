## 业务目标

让负责人能回答：发生什么、为什么值得管、优先管哪一组、今天能做什么、何时看效果。复用样例主动回看旧结论、增加证据、修正误判、分层找瓶颈、比较历史并作出行动选择的深度，不复制版式或堆长摘要。策略研究不授予生产改价权限。

## 必须防止的样例错误

1. FC26 92.62%–97.67% 与 FC27 88.48%–93.98% 实际重叠 92.62%–93.98%，不可称完全不重叠；均值比较仍需分母、成熟度、有效天数可比。
2. 金额差 -3537.91 不得格式化成 -3537.91%；68.75 不是含 69.81/69.17 的区间最高值；5.79 不低于 5.44。交叉计算核验而非免责声明。
3. 历史回填不证明最新值必然上修，也不能证明广告下降不是恶化；同采集时刻不等于同成熟度。
4. 某 FC 异常池为零不等于无派单问题；另有 468 未分配单时必须核定义、覆盖、状态迁移和供应商字段。
5. 老单、零交付、不可恢复是不同集合；需账龄×交付数量×当前原因×最新联系证据，不得因单龄直接建议批量退款关闭。
6. 池净减少率不是队列交付率。以脱敏稳定订单标识追踪完成、退款、取消、重新打开；只有汇总时只能称净变化。
7. 不同下单日分布的 76/70 个样本不能直接代表原因占比趋势；分层补样、保留未知，零样本事件不代表整体归零。
8. 全站券额除以 FC 销售不能当 FC 成本/利润底线，更不能证明获客净收益。
9. 利润、履约相关性不证明共同机制；需价格、成本、产品结构、成本记账时点的补证。
10. 全站流量不等于 FC 流量，单日 ROAS 不足以调预算；核 FC 系列/落地页、归因窗口、转化动作、去重、回填、毛利与履约承载。

**经营主源为 Admin；Order 仅提供参考利润、估算及必要运营明细。** 字段名不证明真实来源，须追踪代码与接口。估算允许明确标识缺口，不要求逐笔完美对账。真实改价成本仅限已核实订单发货类型，排除采购打款、空/未知类型。

## 调查流程

1. 读取背景、目标、策略及上一期未结事项，确定支持的决策。
2. 读取主指标及合理对照，检查覆盖、成熟度、单位、分母及状态定义。
3. 形成可检验问题和竞争解释，按信息价值选择下一次查询。
4. 自主补取明细、历史、交叉维度；新发现允许改计划，不把可查询工作退回用户。
5. 用受控计算生成事实表，查反例；缺口不能被填成原因。
6. 按经营价值排序，给对象、动作、条件、投入、风险、撤回、复查；量化需计算依据，不编收益。
7. 验证后输出短结论及可展开专题；不强制三条，不禁止有依据数字，不以卡片截断调查。
8. 保存证据、判断、建议与动作状态，下期先复盘。生产执行仍独立授权、幂等与读回。

模型不可用时标“分析未完成”，事实/规则提示可保留，但不能冒充 AI 调查成功。可查失败原因与恢复状态；未知调用不自动重试、不重复扣费、不覆盖好结果。

## 首批验收题

| 题目 | 必须通过 | 不通过 |
|---|---|---|
| 复盘履约告警 | 旧结论、旧快照、同日新值；区分真实交付与回填，保留存量风险 | 仅称完成率上升或抹掉旧判断 |
| 销售升利润降 | 量价、结构、成本时效、让利；核最重要的至少两种解释 | 自动归因降价获客或成本上涨 |
| 老单积压 | 账龄×进度×状态，给可推进组与人工确认组及筛选条件 | 只说客服核查或把老单等同无法交付 |
| 月目标风险 | 区分已完成/进度领先/预测；算缺口、所需日均和情景 | 进度达标说成月目标完成；无假设直线预测 |
| 定价研究 | 平台/SKU新鲜有效成本、完整竞品报价，量价/履约风险情景 | 参考利润当真实采购成本、猜未知成本、自行上线公式 |
| 投放与活动 | FC范围、同成熟度转化、活动时点，动作或暂缓的依据 | 全站冒充 FC、单日 ROAS 搬预算 |
| 追问根因 | 补取新维度/事件/历史，更新证据和结论 | 重写原答案或复述三张 KPI 卡 |
| 数据故障 | 部分页/锁忙标缺口，继续独立分析，修正数字矛盾 | 缺失记零、旧证据当新、模型失败显示完成 |

## 替换放行条件

以相同 FC 问题、数据范围和截止时点并列评审。关键结论可追溯，无影响决策的数值/方向/量纲矛盾；至少一个真实自主追加调查案例和一个真实跨期修正案例。建议有具体对象、动作、条件、复查标准，不凑数。记录数据可靠性、耗时、调用成本、建议采用与复盘结果；不恢复用户取消的低额度试点限制。

日报、KPI、定价分别验收。用户先认可真实 FC 成品，再将相应入口默认切到 Hermes。旧历史和回退入口保留，逐项替换推理层，不全量重写采集/改价/调度。安装框架、skills、CI 或 HTTP 200 都不等于业务通过。
