# FS 自主调查与自动回存合同（2026-10-14）

负责人/单一发布者：当前 Hermes 施工任务；业务 owner 吴律。范围：FC 聚合/脱敏只读经营调查、专用结果区。现有 FS 进程派发服务器 Hermes Runs，自主选择已注册数据接口和计算工具；聊天及个人电脑不参与持续运行依赖。

## 输出与恢复

原生模型完成且代理无在途请求后，先原字节保存正文、公开工具证据与 owner/task/run 收据，再生成离线 HTML，最后写小型任务回执。正文采用完整中文 Markdown；长 JSON 和每个数字绑定表不再是可读报告的前置条件。没有可读证据时可交付明确的缺口说明，不能冒认为原因调查通过。

HTML/正文/索引下载均经现有登录、owner/task 查询和内容 SHA 校验；仅固定文件枚举，没有通用文件读写接口。报告包含证据来源、期间和估算/限制，建议未执行，业务验收仍由负责人判断。

结果回存失败进入 REPORT_PENDING，专用结果已保存；同一 FS 进程自动按 5–60 秒有界退避补交结果，重启后可恢复。恢复不调用模型、不重采集、不重复成功步骤。已完成原生分析/处于结果投递时取消返回明确 409，不伪称接受停止；运行中取消仍撤销调用授权并等实际在途停止。

仅当前 DeepSeek 直连 ConnectionResetError 可新建连接恢复本次逻辑调用，最多两次，等待 2/4 秒并检查取消。每次真实 HTTP 请求各保留独立未知/成功记录与安全 Request ID；未知不改成成功或零。HTTP 审核/权限错误不重试，连续断线耗尽明确 FAILED。旧失败任务不重放；另建新任务可继承 owner 绑定的公开证据，0.4→0.5 是此次明确兼容桥，不含私有推理或会话重放。
