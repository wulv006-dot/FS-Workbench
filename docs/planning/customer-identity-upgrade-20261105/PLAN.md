## 身份升级验收矩阵

| 情况 | 必须核实/保留的行为 |
|---|---|
| 同buyer_id多单、UID为0 | 可识别游客重复购买的条件必须由实际字段证据支持 |
| 同buyer_id同时出现注册UID | 游客与注册是否同人要核关联，不一概拆开或盲目合并 |
| 同UID多个buyer_id、同buyer多个邮箱 | 明确账号变更/共享或上游异常语义；保留冲突证据，不模糊合并 |
| 历史没有buyer_id | 精确邮箱旧路径继续可用，标识字段覆盖，不能丢旧客户 |
| 跨站同ID | 保留站点范围，不能自动当全站全球唯一 |
| 同日任务重跑、部分分页失败 | 按订单主键幂等；失败窗口不推进为完整、不删除旧好数据 |
| 新单迟到、老单退款/成本补录 | 复用已存在增量复核路径，不重拉全部历史、不静默冻结异常 |
| FS列表/详情/导出/Hermes | 同一快照、同一身份规则版本和统计范围 |
