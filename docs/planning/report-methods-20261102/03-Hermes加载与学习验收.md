加载验收要求服务器文件及原生技能读取一致；理解验收要求Hermes解释并完成公开算例；迁移验收使用未提前提供答案的新数据。分别记录结果，不能用一句“已记住”替代。

本轮维护Hermes原生记忆与技能，不实施FS改造。用户已明确：FS是原生Hermes对话的承载窗口，Hermes自主理解、取数、调用工具、计算和组织回答，FS如实显示其原内容，不再二次改写或硬套模板。旧FS接口、工具清单和装配只解释当时环境，不是未来能力上限。此为改造目标，实际接通与呈现另验。

报告教学没有修改价格、预算、业务排程或核心自动化，也没有审批其他原有待审技能。用户随后单独授权用两个指定文件配置API，这项已完成，结果见后文。已有会话的旧输入不冒称已自动重载。
