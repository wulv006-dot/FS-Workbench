# ELD独立观察与自主定价接续

用户2026-10-26授权新增ELD，并确认我们不能高于Lootbar和ItemD2R，40%预警/50%紧急复核。定位和复核已由PR485上线，当前八文件映射仍沿fc-owner-pricing-20261026；本批只新增ELD观察，不改定价权重、业务调度、成本、红线、权限或原ID/UNKNOWN。

## 实际接入

- 复用原fc27-price-observer.path/service，原常规auto_cycle/system-automation完成后，在原观察记录保存ELD三平台。存在任一collection_retry_root/of/attempt字段即排除，人工或派生恢复不补采。不新增计时器/模型/采价或改价工单。
- ItemD2R与原权重模拟仍复用原run。ELD执行前释放全部FC业务锁，只保留observer自身互斥；一个原run最多一次，失败保留，不用旧价补成本或新价。
- ELD使用既有固定镜像的独立匿名临时Chrome，不接FC/Admin/Order CDP/profile，不挂卷、不开放端口，无账户/购物车/结算。768MiB、0.5CPU、pids256、init/自动回收，内部65秒/外部80秒；超时仅终止本次确定名称容器，清理未知明确标记。
- 首次公开校准按独立operation_id保存在eldorado-initial.json，明确不是自然工单，不进入自然周期数量；有新自然失败时展示失败，不回填旧校准价格。
- 原API/观察面板添加ELD；原五站市场/0.6、0.7、0.8研究模拟与80/15/5生产参考均不纳入ELD。初始直接生产权重0，作为C2C市场压力的独立信号。

## 比价口径与已知边界

每平台首屏最多50行、目前实际8卖家，保留卖家/信誉/评价/库存/起购量/每K美元/交期/真实捕获时间。只有起购量≤100K且库存≥100K才显示100K数量合格报价；300K起购商家的100K折算价不冒充可购买100K。未逐卖家验证交付方式与最终结算费，不称全站最低、同服务可执行价或采购成本；全球最大份额是用户给定背景，不作为已核实统计。

## 自主定价实际机制与后续方向

第一阶段已实现：80/15/5只是市场参考，服务定位上限和真实成本双10%优先；40/50触发原Hermes同run复核及原告警，比较保持/降价的毛利额与所需订单变化，不依赖模型盲追锚价；同市场已有真实人工意图亦可保持。原11:51自然轮Hermes已实际选择主机保持7.39、PC降至8.68，未采用主机9.30的高毛利候选，证明这次并非机械跟随Lootbar。

下一阶段利用现有4小时研究按真实版本、价格时点与同范围订单/流量/成本/毛利额作前向比较，先积累证据，逐步判断80/15/5能否减少。ELD只观察市场压力，不预设弹性/利润目标或直接追最低价；不得把价格相关性或条件保平订单倍数说成已实现利润提升。研究不恢复暂停的FC/RPG故障内存跟踪，不另发模型/采集/价格工单。
