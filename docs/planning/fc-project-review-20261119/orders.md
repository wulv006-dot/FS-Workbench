## 订单金额、客户和发货

- 买家人数按站点和 ES `buyer_id` 去重，同窗首次付款单的原新老客标记确定该买家的分组。订单和对应金额仍按每单 ES 标记统计。累计金额档按单个买家在完整区间的已付款美元总额再分箱，单笔金额档同时提供。两窗首购标记各有覆盖，无法确定标记的顾客保留未知。
- 优惠采用同单 ES 优惠美元总额除以 Admin `before_discount` 总额，缺分子／分母的订单不参与加权。来源窗口和覆盖随 JSON 返回。
- Players／SBC 商品实收仅统计可证实完整订单单 PID 的付款事实，原生商品排行提供代表标题。多 PID 订单仍计整单类别，不把整单销售均摊到单品。
- 主采购毛利按 Order 发货交易日。由六个既有单日缓存回查同窗原生汇总，去重全部唯一发货记录后求销售减采购。分类毛利保留已归属小计和未归属金额。
- 归档内的付款至首次观察到发货只作为诊断。完单时间、全历史问题事件和真实完成率需要接入独立、同订单的交付事件证据。
