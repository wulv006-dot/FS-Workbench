# 开发与相关检查

执行规则只见 [HOTFIX](ops/HOTFIX.md)。先读受影响源码及模块现有requirements/合同，保持相对路径和当前活动来源；不按本机绝对路径建立新部署依赖。

小修复用PR自动pr-fast，它解析改动文件并只跑已映射受影响组。未映射项补一次最小实际检查，不把全仓扫描或历史清单刷新作为日常前置。目标运行版本按受影响模块合同核对，缺环境真实报告，已有允许路径可继续。

tools/check_candidate.py 是历史整包验收工具，依赖冻结UPLOAD-ALLOWLIST；不是当前main默认快测命令。不得把其旧集合差异当业务源码故障，也不能据进程退出0推导所有测试通过。长回归可另按目的执行、如实验结果。

真实凭据、用户数据、生产价格和运行数据库不用于PR CI。config/examples只示范结构，不能当现场配置。Python/Node及其它依赖按实际受影响模块使用；不为了文档或普通小修自动安装整套开发依赖。
