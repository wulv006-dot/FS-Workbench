# 后续运行、发布与回滚

当前没有发布动作，也没有自动发布workflow、SSH密钥或部署连接配置。GitHub代码审核与生产发布是两步；PR合并不能自动触发采集或改价。本候选中的既有运行入口含真实业务写能力，不得用于本地候选验收。

未来单独获准发布时：从已确认commit生成精确白名单和SHA，核对当前规范源/实时目标/依赖/账本；串行部署，保全受控备份并验证其SHA；不取消进行中的发布。统一经营HTML仍走现有release_gateway，先检查版本、旧基线、未知覆盖、7依赖和锁；staging不得链接到活动源，替换symlink本身，不向链接目标写入。
