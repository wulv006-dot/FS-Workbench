# 模块发布与回退

流程与授权规则只见 [HOTFIX](ops/HOTFIX.md)。已授权模块修复沿用既有publisher和发布锁，必要检查、备份后连续执行；merge不另授生产权限，归档不阻断真实恢复。

发布核本次载荷的来源/版本、当前现场基线、直接依赖和可用备份，按现有模块合同串行替换并读回。未知覆盖、越权、错价或不可恢复风险先解决；无关模块未验不要求全站重测。

回退沿同一已授权恢复范围及既有受控合同；范围不足时一次说明具体缺口。选择确切发布与当时依赖，保留DB、账本、角色、凭据、队列、锁、回执、策略和审计，不能用旧ZIP/整库覆盖。unknown先查原ID和现场结果，不能盲重试。

统一经营HTML仍走原release_gateway及其版本/依赖/锁/有意回退守卫；不修改它的实际实现或借本规则绕过。staging不得指向活动源；不恢复退役publisher、不顺带停正常采集或修改有效调度。

版本/业务结果从真实入口读回后才报恢复；备份及真实配置留在既有受控位置，不入Git。长资料与截图后补。
