# AION2 金币三源跟价 · 改造说明（2026-10-01）

## 一句话

把 AION2 金币的跟价基准从「只跟 IGGM」改成「**G2G + ELDorado + IGGM 三源比价**」，
并且**三站抓取全部搬到服务器用纯 HTTP 跑** —— 电脑关机也能自动抓价。

---

## 一、需求与最终口径

### 用户原话（2026-10-01）

> 「永恒之塔2 金币价格要紧跟 G2G 和 ELD……提取 G2G 和 ELD 的最低价作为参考，
> 并且要比他们低 5%，IGGM 的只做参考，IGGM 一般不会比上面两家还低，
> 如果比他们还低，那就跟 IGGM 的价」

> 「有些区服其他平台没有就先空着，然后这个本地抓取我不是很满意，
> 后面我电脑可能要关机，那你这个没法帮我抓取并改价了啊」

### 落地规则

```
① 基准价 = min(G2G 最低价, ELD 最低价)
② 若 IGGM 价 < 基准价  →  基准价 = IGGM 价        （IGGM 更低才跟）
③ 两站都没数据的区     →  同大区已有区的最低价均值兜底
④ 目标前端每 M 价      =  基准价 × (1 − 让价百分比)   （默认 5%）
⑤ IGGM 抓取价 ÷ 1.1    =  客户真实看到的价         （机房 IP 加价还原）
```

### 服务器实测结果（2026-10-01）

| 源 | 最低价（$/M） | 覆盖率 |
|---|---|---|
| G2G | 7.24 ~ 7.25 | 31 / 34 区 |
| ELDorado | 13.97 ~ 15.00 | 20 / 34 区（新增 14 区全无） |
| **IGGM（折算后）** | **5.445 / 6.355** | 34 / 34 区 |

⇒ **IGGM 折算后最低**，所以 34 区全部命中分支②「跟 IGGM」。
这正是用户定义的规则；G2G / ELD 作为**上限保险**保留（IGGM 异常时兜住）。

## 三、关键接口

### G2G

```
GET https://sls.g2g.com/v3/offer/search
    ?seo_term=aion-2-kinah
    &region_id=<RID>&country=US&currency=USD
    &page_size=100&page=1
    &sort=lowest_price&group=0&v=v2
```

- `group=0` = 全部卖家（不是每区一个代表），`sort=lowest_price` 全局升序
- 按 `offer_group` 末段（服务区卡片 ID）分区取 min = 该区最低价
- 大区 region_id：
  - US `dfced32f-2f0a-4df5-a218-1e068cfadffa`
  - EU `ac3f85c1-7562-437e-b125-e89576b9a38e`
  - Asia `7d971a93-e541-4055-8fcd-eb942b65701a`
  - SAM `5b2d2761-128d-4185-9f42-6c502df03516`

### ELDorado

```
GET https://www.eldorado.gg/api/predefinedOffers/augmentedGame/offers
    ?gameId=360&category=Currency
    &tradeEnvironmentValue0=<大区>&tradeEnvironmentValue1=<服务区>
    &pageIndex=1&pageSize=150
```

- 返回按价升序的卖家列表，取第一条 = 最低价
- `pricePerUnit.amount` 是 $/K，`unitSystem=Unit1000` → ×1000 = $/M
- 区服树：`GET /api/library/360/Currency?locale=en-US`

### IGGM

沿用现有 `core_iggm.goods_ajax_gold()`：先 GET 品类页拿 `__cf_bm` 再打 ajax。

## 四、踩过的坑（避免重复排查）

### 1. 服务器 Python 的 SSL

`/usr/bin/python3`（3.9.18）的 `ssl` 模块**不可用**，urllib 无 HTTPS handler，
报 `URLError('unknown url type: https')`。

**必须用 `/opt/d4follow/venv/bin/python`**（OpenSSL 1.0.2k，HTTPS 正常）。

验证方法：
```bash
/opt/d4follow/venv/bin/python -c 'import ssl; print(ssl.OPENSSL_VERSION)'
# → OpenSSL 1.0.2k-fips  26 Jan 2017
```

### 2. 服务器跑不了 playwright

CentOS 7 glibc 2.17，playwright 自带 node 需 GLIBC_2.28 → 报
`Connection closed while reading from the driver`。

⇒ **浏览器方案在服务器不可行，纯 HTTP 是唯一出路。**

### 3. 报价脏数据（两道闸门）

**① 库存有效性闸门**：`可用量 ≥ max(起售量, 1000)`

实测：G2G `EU Marchutan` 有卖家挂 $6.99 但 `available_qty=2`、成交 0 单；
`Asia Siel` 有条 $7.10 库存仅 98。若照单全收，EU 目标价会被压低 3.6%。

**② 离群保护**：低于「同区多数派中位数 × 0.5」判为脏数据

实测：ELD `Europe Vaizel` 有卖家挂 $1.7/M（其余 18 家都在 $14.9 以上，差 10 倍）。

### 4. G2G 分页

`page_size=100&page=1` 就够（100 条 > 31 区）。因按价升序，每区最低价必在 page 1；
page=2/3 只会更贵。

## 五、回滚

### 方式一：只关三源（推荐，秒级）

编辑 `/opt/d4follow/config.json`：
```json
"金币": { "多源基准": { "启用": false } }
```
重启：`systemctl restart d4follow`

⇒ 退回纯 IGGM 口径，AION2 与其他游戏行为一致。

### 方式二：完整还原

备份目录：
