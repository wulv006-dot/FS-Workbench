生成改价工单（服务器算 · 服务器执行）

这里只负责算准该改什么并生成工单，真正的写请求由执行方发。默认执行方是服务器自己（新机 IP 已在 order.p2pah.cn 白名单内；看板「④ 执行器」段可切换成「本机执行」）。请确认已看过「改价计划 DRY-RUN」的输出。
工单生成后自动派给执行方（执行器在跑就自动执行：写价 → 复核 → 清缓存）。
执行器不在线也没关系，工单会排队等待，不会丢单；也可在看板把单改成另一种执行方式，或手工跑：
python p2pah_local.py write --plan "<工单文件>" --confirm
