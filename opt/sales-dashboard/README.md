# 销售数据看板（Aion 2）

给销售总监看**各推广人成果**的看板。数据来自两个后台，本地抓取、本地渲染。
本地调试双击 `start.bat`；**线上版部署在新服务器 `https://47.85.224.112/sales/`**
（统一登录门户鉴权；数据由本机采集后推送，服务器不直接连后台——服务器到 p2pah 不通）。

## 一句话启动

双击 `start.bat`（或 `python start.py`）→ 自动抓数 → 浏览器打开 <http://127.0.0.1:8899/>。

* `python start.py --refresh` 强制重新抓取
* `python start.py --no-open` 只起服务不开浏览器
* 页面右上角「↻ 重新抓取」同样可以重新拉数
* 看板里的筛选、排序、导出全部在浏览器本地完成，**点筛选不重新抓数**

## 推广人怎么认

按优先级三级归属（`collector/aggregate.py`）：

1. 订单带 `discount_code` 且该码在折扣码配置里 → 归属到**码所属会员**（配置的 `uid` 字段）；
   若该码没绑会员，退到**码归属的后台账号**昵称。
2. 无码 / 码未配置 → 用订单 `recommend_uid` 反查会员。
3. 都没有 → 「自然流量 / 无归属」。

**身份键 = 会员 uid。** 同一个人可能既靠折扣码带单、又靠推荐人带单，
统一用 uid 做键 → **一个人只出现一行**（行里「归属方式」用标签同时标出
`折扣码 + 推荐人`）。早期版本按「来源方式」拆键，导致同一个人出现两行、金额被拆散，已修。

## 利润率口径（重点）

**不是**逐单利润率求平均，而是**先汇总再相除**：

```
推广人利润率 = (Σ 发货记录「￥销售价」 − Σ 发货记录「￥采购总价」) ÷ Σ 发货记录「￥销售价」
```

分子分母同币种（人民币），只取发货记录里 `交货类型 = 订单发货` 的行
（排除采购打款 / 销售补发 / 销售赠送）。没有发货记录的订单**计入单量与销售额、不计入利润**。

订单侧的美元金额（`amount`）另列，用作"卖了多少钱"的直观口径。

## 看板有哪些功能

* **筛选**：日期区间（含今日/近7天/近30天/全部快捷键）、
  **推广人下拉**（自绘组件：搜索框 + 勾选列表 + 全选/反选/清空 + 已选 chips 可单个 ✕ 移除，
  每项显示「名称 · 归属方式标签 · 本期单量」）、
  **折扣码下拉**（同上，每项显示「码 · 归属后台账号 · 本期用码量」）、
  归属维度、有效单/全部/仅退款、关键字（单号 · 邮箱 · 区服）
* **KPI**：订单数、销售额(USD)、销售额(￥)、采购成本(￥)、毛利(￥)、**综合加权利润率**、客单价、用码占比
* **图表**：每日销售与毛利趋势（柱=￥销售额且按利润率着色，折线=USD）、推广人毛利 Top10、
  区服分布、国家分布、支付方式分布
* **推广人成果排行**：**归属方式** / **名下折扣码** / 单量 / 销售额$ / 销售额￥ / 采购￥ / 毛利￥ /
  **利润率** / 客单价 / 毛利占比 / 退款；列可排序（默认按毛利￥降序）；
  **点某一行下钻**看该推广人的订单明细
* **折扣码效果**：每个码的**归属后台账号**、用码单量、产出、让利金额、**实际让利率**
  （= Σ让利$ ÷ Σ原价$）、采购￥、毛利￥、利润率、首末单日期
* **订单明细**：分页浏览 + 列排序
* **导出**：把当前筛选结果导成 CSV（Excel 直接打开，带 BOM 不乱码）

> 折扣码模块**只显示码本身、归属后台账号与实际让利率**，不显示会员账号等内部字段
> （早期版本把「码 · 会员脱敏邮箱」混在一起显示，看起来像重复数据，已改）。

## 离线单文件版

`build_offline.py` 把 `web/index.html` + `data/dashboard.json` 打成一个自包含 HTML：

```
python build_offline.py     # → 销售数据看板_AION2_离线版.html（约 1 MB）
```

双击即可打开（`file://`），**不需要起服务、不联网**；数据是打包那一刻的快照，
「重新抓取」按钮会提示改走服务版。适合发给同事、或服务没起的时候应急看。

## 表格用法

三张表（**推广人成果排行 / 折扣码效果 / 订单明细**）各自带**独立筛选框**（在卡片标题行右侧）：

* 推广人成果排行：可筛 UID、归属方式、名下折扣码、归属后台账号
* 折扣码效果：可筛折扣码、归属账号
* 订单明细：可筛单号、推广人、折扣码、区服、状态、商品名

筛选**只作用于本表**，不影响其它表和顶部筛选；右侧计数显示「命中 / 总数」，无命中会变红并提示。
表头已**冻结**（sticky），表内滚动时表头固定并带投影，首列冻结表头会显示蓝色左边条。
