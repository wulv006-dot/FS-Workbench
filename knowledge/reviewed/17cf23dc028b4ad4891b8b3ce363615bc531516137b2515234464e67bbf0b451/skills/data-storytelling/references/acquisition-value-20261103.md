# 获客成本、客户价值与通俗经营汇报

2026-11-03。供团队和Hermes按需读取。原则适用各游戏；文中FC数字是本次历史案例，不是长期预算或售价规则。

## 先回答经营问题

先说明广告是否值得继续、哪里需要改善、客户多久回本，再展示关键图表。正文写“根据历史客户数据核对计算”，内部抽样、分组、核验和脚本过程保留在私有证据。用户给出新的已确认口径后，联动更新广告、价格优惠、国家、产品、复购与排期建议，不能只换一个数字。

使用熟悉语言：“每个新客花多少钱”“每花1美元带来多少销售”“第一次进入哪一页”“后来有没有再买”。术语仅在来源说明中出现。数字与比较用图，文字解释意义，不再复读全部数据。主结论不被细微口径差异拖成审计清单。

## 1. 自然流量：先分清到底在数什么

- GA4 `pagePath` + `sessionSourceMedium=google / organic` 的 `screenPageViews`：自然来源访问中看过该页面的浏览次数，可重复。
- 同条件无页面维度汇总的 `activeUsers`：该范围去重活跃用户。不能把各语言页用户数直接相加。
- `landingPage` + `sessions`：一次访问的第一站是该页，未包括先看其他页再来到该页的访问。不能用它代表商品页全部访问。
- GSC点击、曝光与GA4浏览不是同一种指标。主英文页包含在全语言总数中，不能相加。
- 固定完整日期、属性时区、精确URL清单和来源过滤。截图未显示日期时，不编截图日期或宣布截图错误。

案例：完整10月FC27主英文金币页自然浏览34,077、全15语言48,177；首次落地金币页自然会话11,076。原值可以同时正确，但不能据后者推断商品页只有一万自然浏览。

## 2. 广告新客成本：用真实来源的首购客户作分母

优先复用Admin原生ES销售订单下载完整表，读取“游戏、订单号、订单状态、付款时间、是否新客户、订单来源、国家代码、订单金额（美元）”。不要因FS投影未带来源就断言后台无字段。

1. 先按游戏、网站、付款范围和真实有效状态筛选，按订单键去重，核完整文件集。
2. 再按新客标记和明确广告来源筛；空白来源为未知，不自动算自然或广告。国家用原表国家代码，系列名称不能代替客户国家。
3. 优先按客户稳定键去重。原表缺客户键时，用Admin同订单补关联；若标记总数与原生去重新客数核平，必要身份抽核支持唯一，可明确采用近似人数，不为小差异无限采集。
4. 费用与分母覆盖相同投放范围。跨游戏和品牌相关系列单列或采用用户确认的综合口径，不能随意全额分摊，也不能漏掉真实FC成交。
5. 广告系列名和订单来源标签不一定相同。需要细分时核实际跟踪参数；当前URL不能证明历史配置。名称相近不够支持精确系列CAC。

`广告获客成本 = 对应投放费用 / 该范围明确广告来源的新付费客户数`。

本次FC专属口径约$53；用户确认包含其他游戏广告系列和品牌相关系列的综合口径约$42。两者分别采用并标来源，不重算用户明确要求直接使用的$42，不反推虚构其费用/人数，不相加、不把差额当某系列贡献。广告费除以全部新客会混入免费渠道，不是广告获客成本。

## 3. 客户长期价值：包含只买一次的人

从成熟首购月份的完整新客候选中，按首单金额分层随机或确定性抽样，抽样发生在查看后续活跃之前。必要时换不重叠样本检验波动；按总体层权重合并。不能只抽仍活跃、复购或高消费客户。

按稳定客户关联后续订单，统计30/60/90/180日及赛季截止累计收入、订单、复购比例、首末付款跨度。固定付款日期、货币、游戏与网站；观测335天不说完整365天。平均首末跨度不是用户寿命：只有一笔付款者跨度为0，复购者单列更便于安排触达。

**真实故障经验：**Admin空付款时间可能返回数值0，必须识别为无付款时间，不能变成1970年并据此把新客误判老客。结合真实`pay_status_format`和订单状态区分Paid、Refunded、Unpaid；有金额或创建过订单不证明付款。退款不能直接丢失，未支付尝试不能算消费。

在私有目录冻结匿名客户/订单哈希、日期、金额、状态与游戏等必要字段，后续在本地重新计算，不每次重新读全部客户历史。邮箱、UID、真实订单号及凭据不进Git或汇报。

## 4. 从价值到可承受广告费

- 主盘实际采购毛利仍取同范围Order发货统计；没有逐客户历史成本时，客户收入乘已核毛利率属于估计，明确来源月份，不冒称实际逐客户利润。
- 按用户指定的理想口径：`可承受广告成本 ≈ 每客累计收入 × 采购毛利率`，不擅自增加费用预留或目标利润。
- 回本期限不同，上限不同。30日、90日和赛季累计分别算，不能用赛季价值承诺30日回本。
- 首单较低可能来自产品、折扣或人群差异，不能直接认定后续收入同比缩小。假设多且不改变主要决策的情景不放正文。
- 免费渠道和老客贡献用于解释全盘经营能力；不要既加进每个广告新客LTV，又用来抵扣广告费用。综合可覆盖不代表净利润，专属偏高也不等于全部广告亏损。
- 退款全额状态扣减可作敏感性情景，不能假称实际退款金额；已扣优惠不再重复减。

案例：每客赛季收入约$163，FC27毛利率28.15%，理想采购毛利约$46。与团队综合获客约$42相比接近可覆盖；专属约$53仍需提效。应保有效获客、优化低效部分、经营早期复购，而不是全面暂停或全面加预算。

## 7. 报告结构：先分付费与自然，再在各模块展开
