# 实例：PC Coins 从商品销量补到商品订单，仍不能把件数当 K

这是2026-10-24在FS“数据分析工具→单品跟踪”真实查询所得，供字段教学与本次日报验收使用。该UI查询由Codex执行；Hermes新任务仍要实际调用同一个接口，不能把本文当作它已调用的证明。

先从 `product_sales` 的PC记录识别真实 `pid=163329345`，不从标题猜ID。再读 `fc.query_product_orders` 的实际schema，调用两次：

```json
{"profile":"FC27","product_id":163329345,"start":"2026-10-16","end":"2026-10-16","max_pages":20}
```

```json
{"profile":"FC27","product_id":163329345,"start":"2026-10-23","end":"2026-10-23","max_pages":20}
```

直接 `product_id` 查询不能同时传 `model_id` 或 `platform`；模型查询是另一种合法方式。日期最长31个日历日。`pending`时按原查询继续读取，不改变参数新开查询。ID由Admin本身的游戏/商品映射核验，不从FS编号做算术转换。

| 原字段/回包声明 | 10/16 | 10/23 | 怎么用 |
|---|---:|---:|---|
| `totals.distinct_orders` | 82 | 66 | 同一PID的去重关联订单数。可说该源订单数下降19.5%，不是卖出82K/66K，也不是82/66个人 |
| `totals.order_amount_usd` | $5,392.80 | $3,730.34 | 关联整单USD。可看这些订单规模，不全部划给Coins SKU，不与商品行金额强行对平 |
| `quality.complete` | true | true | 本查询读取覆盖合格；不代表数量定义、交付K、财务净额也已齐全 |
| `quality.item_quantity` | 两期均声明购买行的x-count，不是商品规格 | 同左 | 购买2件不能自动换算为200K、1000K或实际交付K |
| `quality.time_basis` | Admin paytime RANGE，时区未核 | 同左 | 先按Admin源付款日期比较；不能擅自拼成北京时间精确暴露/小时因果 |
| `captured_at` | 2026-10-24 03:53:16.825610 UTC | 2026-10-24 03:52:31.020100 UTC | 采集时间，与订单所属日期分开 |

读取 `products[].groups[]` 时继续按以下顺序：

1. `order_status`、`payment_status`：先分状态。当前状态不是历史日末，退款未结不能称已实现收入。
2. `orders`、`known_amount_orders`：核金额分母。`known_amount_orders`不足时，不把部分已知金额当全部金额。
3. `known_line_orders`：核目标商品行能否唯一匹配。匹配不足时不能拿整组订单数当商品行覆盖。
4. `quantity`：源程序仅在该组所有订单商品行已核时给合计，否则null；null保留未知，不补0。即使不为null，单位仍是购买件数。
5. `item_line_by_currency`：目标商品行原币金额，USD、GBP、EUR等分别列示；不直接相加，也不拿USD整单额减GBP商品行额算优惠。
6. `mixed_orders`、`coverage`：识别混合订单、分页总数、稳定行身份、重复与冲突；不能把订单总额当SKU净收，更不能把标题当实购档位。

用于下一步判断的链条是：**关联订单下降已证→关联整单均额也可计算但不是单位价→还需具体选购K、赠送K、实际交付K、SKU同币种净收入及优惠资格→才有条件拆分档位/数量/单位成交价。**

例如，`3730.34÷66`是这些关联订单的整单均额；它不能代替 `SKU净收入÷实际交付K`。如果接口没有投影K规格，就明确“已查商品销量和商品订单，当前返回件数而非K；无法证明单位价变化”，同时继续处理已经可以确定的订单拖累、商品页与流量线索。

两期源版本分别为 `bc653f4f10eb5ff1bccae4cadba5acd4ce2adbd2af7ba508a1802d3e042a8554`、`1122bba1afb11291cf323e0fc693398fda9f3497e14c6234da241896cb2e7ce6`。UI回执在本任务私有证据目录保存；未导出原订单身份或客户资料。
