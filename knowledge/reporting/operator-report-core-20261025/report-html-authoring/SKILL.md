# 经营报告创作方法

## When to Use

- 需要经营日报、周报、月报、区间复盘、专项分析或简短经营问题解读。
- 用户反馈旧报告质量、理解或排版问题，需要重新分析或调整呈现。
- 需要把真实证据转为易读图表、关键分析、建议或简洁回答，具体设计自主。

## 判断与方法

报告服务读者判断和行动。围绕本次要决定的问题，给有主次的全局判断、价值取舍与建议，用关键事实说明理由，再落到行动与复查。现有证据足以支持方向时承担判断；只有差异可能改变主次、行动方向、重要金额或造成实质误导，才继续补证。推断与事实分开，不编造精确因果或已执行结果。

成熟原生Hermes结合会话、记忆、Skills与实际工具自主安排调查、分析和表达，不固定分析步骤、章节、句数、图数或阅读顺序。长期记忆保存用户偏好与稳定入口，当前方法和工具合同按任务读取；不默认注入整本教材。软件发布器只负责软件安装与回退，真实actor、数据范围、财务、writer、原ID、幂等和UNKNOWN由工具边界负责。

按需读取当前[FC报告知识入口](../../fc27-monthly/README.md)及[取数与计算](../../fc27-monthly/DATA.md)，其他游戏回到对应当前来源合同。METHOD.md、APPLICATIONS.md与ACCEPTANCE.md只参考本次适用部分，历史来源或案例不覆盖现行合同。实际工具schema、权限、响应与覆盖决定本轮能做什么，安装或目录存在不证明已经取数或加载。

## 事实、来源与计算

为本次分析保留期间、对照、游戏、网站、时间字段／时区、采集时刻、来源、原值、状态、单位、分母和缺项。正文、卡片、图表与原值表使用同一份经核对的事实，不沿用案例数字。可比窗口按问题和实际来源选择，当前日说明截止，缺日或失败不补零。

来源按每行实际响应的系统、模块、endpoint与范围标记，不按报告类型预设primary／supplement。Admin订单统计、支付明细、原生品类／问题聚合的模块和分母不同；Order状态明细不标成Admin。不同网站、游戏或群体先核可比性，不缩放原值强行核平。

FC主采购毛利按当前Order发货统计的同范围人民币销售减采购；全局率按总毛利÷同统计总销售，不平均各日或游戏比例。Admin付款销售与发货统计不是同一订单群体；同批逐单实际成本按需独立分析，保留覆盖，不外推全体。旧Admin销售乘参考率的估算不能替代当前主毛利；没有完整费用不称净利润。具体公式与接口边界回源当前DATA和模块合同，不凭字段名猜口径。

金额以来源精度计算，最终展示再舍入；不改原值凑平。订单量×客单的拆解是算术关系，不能直接证明价格因果；缺实交K时，订单数、件数、客单和整单均额不代替每K价格。建议阈值须有依据，标“建议”不使其自动有效。

履约比较区分当前老池与新付款批次，核订单年龄、状态、实际等待及覆盖；同一快照较新批次完成率低不能排除年龄解释。精确定量须有同批历史快照。客户人数、ES标记订单、广告新客和GA4新用户不混同；未跟踪同批客户，不把当期复购变化归因于促销或当作成熟LTV。已扣优惠的收入不重复减优惠。

Ads按真实channel_type与归因成熟度解释，平台0转化不等于0真实付款。GA4、GSC、Ads、Admin和Order各保留对象、时区与来源范围；一个子源缺失不抹掉其他有效子源。重要获客或商品问题按实际价值展开，不要求每个品类凑同一套工具或章节。预算、价格、折扣及实际写入沿当前授权与原执行器。

## 表达与阅读体验

简单问题直接给简洁文字；复杂分析按需使用图表或交互HTML，不强制每次出页面。标题讲业务判断，文字解释数字的含义而不逐项复读。重点结论与关键证据默认可见，详细原值、算式、来源和限制可展开；不能让读者点开很多处才理解主线，也不删成只有图表。

分析、图形、配色、字体、布局和阅读顺序由Hermes按任务选择。报告HTML的FS视觉只作参考；此设计自由不扩展为FS工作台或全站样式变更。保持清楚的层级、宽度、留白、行长和紧凑密度；需要修改已认可成品的版式时复用其有效数据，保留原稿与修订依据，不无故重跑取数。

比较按需用适合的图，期间／维度／指标切换同步标题、单位、来源、对照和数据。金额、人数、百分比与百分点不混用裸轴；比例按合法分子分母算，不简单相加或平均日报比率。缺失不补0，不可比期间不连成趋势；情景、预测和真实结果分别标明。涨红跌绿表示方向而非好坏，同时保留符号或文字，不只靠颜色。

HTML交付需要时提供完整离线文件，内联必要CSS／JS／数据，不混入Markdown代码围栏或任意外部脚本、字体和网络请求。图注写单位、范围、来源与重要缺口；语义figure／figcaption，SVG使用可访问名称及适用的title／desc。控件可用键盘且焦点可见；宽图在局部容器滚动，手机页面不横溢，图中文字可读。浅暗主题、打印与离线重开保持必要信息。

FS嵌入的sandbox／srcdoc目录须在当前文档导航。保留原生链接的可访问名称；需要时阻止父页base导航，在当前文档scrollIntoView并将焦点移到目标标题，不更改父页、网络或历史。从实际FS报告入口检查点击和键盘，不以独立文件可用代替嵌入验收。

## 核验与复用

先看能否帮助判断、主次取舍与行动，再核逻辑、语言、视觉和会改变结论的数据问题。成品结构检查不代替浏览器质量验收；HTML检查相关桌面／手机宽度、主题、切换、展开、键盘、打印与下载重开。没有对应能力就如实写未验；检查绑定最终文件SHA，修改后仅重验受影响部分。可按需参考references/verification.md，不为简短问答强加页面流程。

真实工具调用、原稿、修订、失败及实际审计／账本证据保留；移除已失效且冲突的默认指令，不另建备份或把旧纠错正文堆进当前技能。客户身份、订单明细、凭据与私有会话不进入共享技能、Git或长期记忆。工具超时／UNKNOWN沿原ID核对，不盲重放；冻结报告的followup不冒称刷新，需要新增来源时沿当前已授权调查入口取证并保留前版。

文件保存、Git／CI、审核应用、目标profile读取、真实报告和自然周期分别报告。不能用本技能文字修改或一次复述证明模型已经学会、软件已安装或业务已成功。
