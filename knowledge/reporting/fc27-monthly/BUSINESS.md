# FC27 业务知识与边界

本页整理月报解释所需的稳定概念。动态价格、成本、活动节点和系统运行状态每次回源；[AGENTS](../../../AGENTS.md)、现行模块合同和已发布源码优先。

| 业务对象 | 月报需要知道什么 | 常见误读 |
|---|---|---|
| Coins | 购买量、赠送量、实际交付K及平台要可比；订单客单受套餐/地区/平台结构影响 | 客单下降直接等于降价；展示 `Price` 等于单位售价 |
| Players／SBC／Items | 真实商品/模型与成交分别核；收入、类目毛利、SKU成本按证据拆分 | 把整单关联金额重复算SKU收入；按收入比例虚分球员/SBC毛利 |
| 会员与优惠 | 注册会员、获券人、用券人、用券单、原生新客分别看；实际优惠USD按金额计算 | 把新客标记订单全部优惠都叫新客活动成本；用券分类当因果来源 |
| 国家／语言／设备 | 国家是客户/实际投放地域，语言是页面，币种是付款选择，下单设备与游戏平台分开 | US页面=美国用户，Mobile订单=PC游戏平台 |
| 履约与验证 | 当前积压池、完成单问题占比、问题处理样本及全量耗时各有范围 | 样本平均当全量；只看中位数掩盖长尾；把金币验证器覆盖扩到全部商品 |
| 自动化 | 原执行ID、结果、读回和真实经营结果分层呈现；已运行、试验中、未来规划分别标 | 上线功能=已创造收入/节约工时；试验模型=已启用策略 |
| 活动 | 真实访问/选品/加购、优惠码关联付款与广告/GA4分别看；官方确认/社区追踪保留来源层 | 活动码关联金额=活动增量，全部游戏活动页广告费=FC专属成本 |

## 当前定价知识只引用权威入口

当前唯一入口是[CURRENT-BASELINE](../../../docs/planning/fc-pricing-v3-20261026/CURRENT-BASELINE.md)与[DUAL20](../../../docs/planning/fc-pricing-v3-20261026/DUAL20-NO-BUDGET-CHANGE.md)。报告不复制动态价表和整套执行公式，先看当轮证据与当前版本；防止旧教材中的双10、七日窗口、全目录红线等退役规则回来。

现行双20硬线仅核购买100K、另赠5K、实际交付105K档；其他套餐仅诊断。该句帮助识别历史冲突，不赋予改价权限。报告任务只读取现有执行/采集证据，不更改价格、优惠、预算、计划或P0常驻链路。建议具体新售价前另核有效成本与当前可比竞品。

## 历史映射与案例

2026年10月复盘已核FC26 Admin game=833、Order game=824；FC27分别1327、1322。它们是原期间来源映射，未来任务从当前目录确认，不把不同系统ID互换。主站与全部网站分别统计；HTML页首全站总盘不覆盖主站同比范围。

历史FC专属CAC约$53、团队综合约$42与赛季采购毛利估计约$46见[取数分册](DATA.md#获客与客户价值)。它们支持当时“保留有效综合获客、改善专属效率、经营早期复购”的判断；未来先更新费用、新客来源、客户成熟度与成本，不照搬扩量/停止结论。

FC节点与需求变化优先官方资料，同时保留公告日期、活动生效/结束及采集日期；MMOEXP新闻不是官方公告，跟踪/预测不提升为官方确认。对活动前后收入的解释还要核获客、平台与订单群体，热度不自动成为新的定价特征。
