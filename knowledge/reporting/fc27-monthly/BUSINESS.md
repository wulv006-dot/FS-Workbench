# FC27 业务知识与边界

本页整理月报解释所需的稳定概念。动态价格、成本、活动节点和系统运行状态每次回源；[AGENTS](../../../AGENTS.md)、现行模块合同和已发布源码优先。

| 业务对象 | 月报需要知道什么 | 常见误读 |
|---|---|---|
| Coins | 购买量、赠送量、实际交付K及平台要可比；订单客单受套餐/地区/平台结构影响 | 客单下降直接等于降价；展示 `Price` 等于单位售价 |
| Players／SBC／Items | 真实商品/模型与成交分别核；收入、类目毛利、SKU成本按证据拆分 | 把整单关联金额重复算SKU收入；按收入比例虚分球员/SBC毛利 |
| 会员与优惠 | 注册会员、获券人、用券人、用券单、原生新客分别看；实际优惠USD按金额计算；新老客仅用已标记订单，另报覆盖率 | 将未标记订单归为老客，或把新客标记订单全部优惠都算活动成本 |
| 国家／语言／设备 | 国家是客户/实际投放地域，语言是页面，币种是付款选择，下单设备与游戏平台分开 | US页面=美国用户，Mobile订单=PC游戏平台 |
| 履约与验证 | 当前积压池、完成单问题占比、问题处理样本及全量耗时各有范围 | 样本平均当全量；只看中位数掩盖长尾；把金币验证器覆盖扩到全部商品 |
| 自动化 | 原执行ID、结果、读回和真实经营结果分层呈现；已运行、试验中、未来规划分别标 | 上线功能=已创造收入/节约工时；试验模型=已启用策略 |
| 活动 | 真实访问/选品/加购、优惠码关联付款与广告/GA4分别看；官方确认/社区追踪保留来源层 | 活动码关联金额=活动增量，全部游戏活动页广告费=FC专属成本 |

## 按实际计划协议读取定价合同

先查实际计划与原操作的 `write_protocol`。现役 `fc27_curve_v6` 使用知识条目 `fc.pricing.constraints`、`fc.pricing.v3` 的当前版本，规则原文见 [FC27 V6.1 经营与执行合同](../../../docs/planning/fs-fc-admin-es-20261112/HERMES-V61-CONTRACT.md)。

- PS、Xbox、PC 各自使用本平台采购成本与北京时间 D-3 至 D-1 三日金额加权平均优惠作报价预测。按此假设核各档保本，主篮子与近期篮子分别核 18% 底线。未启用 `margin_band` 的 V6.1 计划用 25% 作经营比较。启用后按计划修订的平台目标 `t` 判断，初始 PS/Xbox 31%、PC 34%。商家支付／履约费用按已确认的 0 计，偶发退款与追回不进入新售价预测，历史流水按原口径保留。
- 售价分低于 1000K 和 1000K 及以上两段。竞品仅实采各平台购买 100K，大额参考由同条件标价和赠币各乘十后按实交 K 比较。报告区分正常基准、经营候选、财务保护后目标与主站已确认价。临时成本保护不改变正常基准，释放时按当轮财务证明重新计算。
- 沿 Admin 保存 ALL 完整价表，以原成功回执和 MMOEXP 主站 site 266 全档读回确认。Order 继续提供订单、采购和利润读取，V6 售价无 Order 同步。报告只读，建议具体售价前须核有效成本与当前可比竞品。

历史标量计划按当时协议和原 ID 复核。双20、D-9 至 D-2 八日优惠和当时的 100K 财务基准见[旧标量合同](../../../docs/planning/fc-pricing-v3-20261026/DUAL20-NO-BUDGET-CHANGE.md)；历史赠币和交付量按原订单记录。

## 定价效果判断

按实际生效的计划修订和确认回执判定策略。旧 A/B/C 只复盘切换前有效价差，影子无执行权。阶段 5 按当时的时段、平台与量段解释目标利润率、预测利润率和竞品走廊截断。周阶梯用整周同单实际采购毛利额及订单量评估 `t`，阶段 4 的溢价 `p` 提议保留原语义。Hermes 通过原 `pricing_review_v3` 取证。

日报、周报、月报按各自原期间汇总实际销售和采购毛利，跨修订只在定价效果复盘时按实际生效时点分段。PS、Xbox、PC 按量段比较实际采购毛利额／小时、实收及已标记新客，报告保留成本覆盖及流量和客户结构变化。跨日取数及异常成本处理见[定价效果取数与计算](DATA.md#定价效果取数与计算)。

## 历史映射与案例

2026年10月复盘已核FC26 Admin game=833、Order game=824；FC27分别1327、1322。它们是原期间来源映射，未来任务从当前目录确认，不把不同系统ID互换。主站与全部网站分别统计；HTML页首全站总盘不覆盖主站同比范围。

历史FC专属CAC约$53、团队综合约$42与赛季采购毛利估计约$46见[取数分册](DATA.md#获客与客户价值)。它们支持当时“保留有效综合获客、改善专属效率、经营早期复购”的判断；未来先更新费用、新客来源、客户成熟度与成本，不照搬扩量/停止结论。

FC节点与需求变化优先官方资料，同时保留公告日期、活动生效/结束及采集日期；MMOEXP新闻不是官方公告，跟踪/预测不提升为官方确认。对活动前后收入的解释还要核获客、平台与订单群体，热度不自动成为新的定价特征。
