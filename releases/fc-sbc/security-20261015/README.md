## 修改

- Nginx复用原internal统一校验端点，透传原方法/原路径；覆盖客户端身份头。服务端所有POST要求受信管理员身份，缺身份401、只读403，JSON边界校验；普通成员不会复用共享Admin会话执行操作。
- 全部可指定表格路径的采集、载入、修剪、保存、下载入口共用输出目录限制，解析后拒绝目录外、符号链接逃逸及非xlsx。SBC专用systemd drop-in限制文件系统仅output/cache和私有tmp可写，移除capabilities；不增加业务账号或权限。
- 自动流水线仅接受明确ok:true；失败/缺失/未知立即停止，不再走后续上架或改价。缓存降级不会被当成本轮最新取价。任务入口和手动/自动共享忙锁修复并发；设置采用原子写，落盘失败不吞掉。
- 下架只有回读status=0才能算成功；超时、状态缺失/矛盾停止后续写，记录unknown。写前持久化本次operation_id，确认后更新；重启后未决回执只先读原模型，不能盲重放。人工需要核对output/delist_receipts.json和原Admin操作，不删除回执制造成功。
- 当前navigation.json精确新增FC类FC27 SBC入口，既有其他工具、顶级区块和字段保持。
