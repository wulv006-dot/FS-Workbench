# FC收入下降：可复算的方法示例

以下全部为合成示例，不代表当前业务实绩、真实动作或效果。

同一主站窗口：对照100单、$1,000；本期80单、$880。收入减少$120。确定性对称分解为订单贡献−$210、客单价贡献+$90，两项合计−$120；客单价$10→$11不证明单位售价提高，订单数不等于金币数量或人数。

1. **事实及范围**：先读取本期/对照Admin主站原生订单与金额，保留渠道行及采集版本；参考率按期、Admin优先/Order补缺。若同期营销尚未完成，经营事实仍可发布，营销只标缺失。
2. **优先调查**：核同期FC相关搜索/落地页与专属广告，明确全站背景；全局品牌PMAX留全局，关联成交要真实来源×游戏交叉表。若FC相关访问与订单同步减少，先把流量减少列为排查方向；只有同范围链路支持时才提升判断。
3. **替代解释**：访问稳定而订单减少时，补支付失败、商品可用性与同类商品价格证据；不把Ads CVR当网站成交率。再查Coins/Items、平台、国家、订单均额与游戏实际发生节点；PS Coins PID是平台产品族，不是单一档位SKU。
4. **履约与损失**：查询本期订单群组交付、取消/退款、CB及原因；当前队列单列。付款额减交付额不能全称积压，日后退款也不能无证据归入本期确认收入损失。
5. **建议动作**：建议运营负责人先核受影响最多的已证实页面/系列；支付负责人核对应错误链路。执行前要有同范围基线及合法修复权限，本报告不自行改广告、定价或派单。停止条件为关键证据不支持原判断、错误/退款护栏恶化或实验范围不再可比；无依据不编改善幅度。
6. **记录执行与复查**：初始状态为建议。用户确认后记录负责人、实际动作、时间及证据，再设下一完整可比窗口复查访问、订单、支付及损失指标。未执行不判策略无效；并发活动、版本节点和价格变化作为混杂因素。有效/无效/证据不足分别记入原行动账本，不回写为永久定价规则。

日报优先复查到期已执行项；周报汇总有效动作及未解问题；月报按真实自然月重新查询不可加指标并复盘适用场景、反例与有效期限。报告原稿、页面、HTML及行动引用保持同一任务和数据版本。
