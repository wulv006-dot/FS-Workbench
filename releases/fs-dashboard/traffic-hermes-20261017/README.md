多个系列没有可核实的聚合有效互动分母时，聚合原生CVR为空；各系列原生CVR可用。主要转化和按互动日期已标明，转化目标配置元数据尚未采集，不混成Admin成交率。GSC内容聚合先于页面Top，但仍受上游隐私与Top限制。
