# FS按需经营读取 · 2026-10-12

将经营读取从两小时全量快照切到原Admin/Order日期查询和共享缓存。保留原来源口径、币种、RPG状态、全部网站/主站区分、利润预估和权限限制。

- `source/`：目录、准确区间、今日/历史摘要、完整日利润、机器查询与周报消费者；运行时继续导入现场既有只读读取器与纯合同模块。
- `tests/`：50余项离线来源/日期/失败/权限/发布断点测试及原生浏览器回归；helpers为冻结的无凭据纯合同测试输入，不部署。
- `frontend/`：15份不可变资产、首页/路由/导航三份激活文件，继续使用原publisher、共享发布锁及CAS。
- `deploy/`：原publisher增加确切9文件范围和单一原timer退役动作；prepare只在服务器私有stage生成DY projects变更，其余凭据、有效期、撤销和利润开关原样保留。

发布顺序：冻结PR并通过Linux离线CI→服务器私有准备→9文件锁内CAS发布、仅重启range/query服务→前端激活→真实入口/历史/利润/两周报告只读验证及DY17项目独立HTTPS→带实际验收及部署SHA的单独退役manifest→停用原`fs-transaction-collect.timer`→再次读回。未满足实际验收时保持timer，不冒称退役完成。

原经营HTML、独立FC经营HTML及旧营销经营模块原字节保留；其重复经营入口通过原门禁进入新版。Google各来源采集、周报定时、FC价格/生产任务、认证、数据库与其它客户端不改。

今日摘要15分钟缓存、历史摘要和完整日利润2小时缓存；缓存不等于定时全量采集。请求日数上限366，长区间上游未标真实日期时不编造每日图点；逐日利润小批读取、缺日为空、今日未完成日不展示完整日率。冷缓存速度依来源及所选日数。

apply/retire不是可盲目重复执行的命令。未知结果先读原releaseId的私有journal与现场SHA；rollback只接受原manifest哈希、原备份及未漂移目标，保留数据库、快照、报告和新缓存。不能恢复被撤销身份。
