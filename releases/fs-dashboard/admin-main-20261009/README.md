# FS 主站视图与页面保持

主站订单和销售额采用 Admin 的 MMOEXP 分站数据。Order 利润率明确标注不同来源与参考范围；预估利润使用主站销售额乘该利润率。缺失值不填零，卫星合计仅作可选参考。

页面隐藏时保留图表、筛选和区间缓存；重新显示时验证登录身份并检查快照版本。登录失效或身份变化仍清除视图，真正离开页面仍释放资源。参考范围选择器沿用现有主题样式。

assets/ 是完整前端源码，asset-manifest.json 只记录这些源码文件的内容校验值。数据由已有受保护服务在运行时提供，目录不含经营快照、凭据、生产路径、部署指令或验收收据。

只读测试入口：`node test-policy.mjs`、`node test-visibility.mjs`、`node test-assets.mjs`。测试采用合成数据和隔离事件，分别检查主站口径、生命周期、源码一致性。仓库现有 pr-fast 调用这些测试，不新增工作流。合成测试不代替真实系统休眠或冷查询性能验收。
