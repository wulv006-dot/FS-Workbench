# Hermes 经营汇报与竞品定价研究分轨

经营日报、周报、月报围绕宏观经营、策略及运营动作、专题与促销规划、履约及问题单剖析。独立竞品与定价研究围绕金币、物品的市场行为、网站比价与市场机会；经营状态仅作辅助背景。二者复用实际证据，不共用报告结构或主方法。

复用已有mode=pricing与只读权限，新增独立技能fs-fc-pricing-research、pricing-v1模板和明确的页面入口、筛选及下载名称。controller与worker使用相同mode/问题选择技能并核对指纹；成稿按report_track选择不可变artifact合同。默认经营与旧报告保持原合同，不按日期将定价混成日报。

只复用当前注册工具：Coins四家三平台100K价格、Order成交成本、主站商品、汇率和EA官方消息；Items外部竞品、网站完整优惠/交付条件及历史价格序列仍按实际覆盖说明。缺项不取消有据市场判断，未核实成本与可比当前报价时不报具体新售价。

原接入综合稿保留为接入验收，不冒充正式独立定价稿。本增量不新增模型调查、定时器、改价或访问权限。真实新定价模型成稿留待用户实际发起；使用合成数据验模板/接线。

测试：python -B -m unittest discover -s tests -p 'test_*.py' -v；node check_tracks.cjs。发布沿用既有受控publisher、锁、CAS、备份、任务静默和回退，固定10目标文件。
