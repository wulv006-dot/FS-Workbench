## 最终行为

- 接受关键判断/结论先行、R/A 编号与表格建议。缺责任角色、触发、成功或停止条件时显示待补；原文未绑定具体证据时明确说明。
- 专项优先读取报告明确声明的对照窗。日序列、平台、品类必须与同快照完整总量核平；完整日分组可提供经过逐行核平的汇总，冲突不按证据 ID 先后任选。
- Order 参考双期日率、地域/设备已知行分别恢复。pending 不覆盖成功，冲突、缺日或不符范围不补零；参考日率不换算为主站利润金额。
- 另存 `boss-semantic-v2-*`，绑定源文件和原研究/结果/证据 SHA。原研究、旧老板 HTML 和原证据字节保留，模型任务不重放。
- 阅读版显示量价精算、T+n、周末贡献、当前队列边界和错误因果勘误。历史建议不会自动成为正确建议，业务接受状态仍为待负责人复核。
- 方法版本 `0.7.0-report-semantic-quality` 使用现有 Humanizer/Marketing 方法，补入证据→定位→竞争解释→验证→决策合同；不保存样板结论、热点或固定门槛。未接通官方网页工具时明确情报未开展。
