# 经营调查生成与审核合同 v2

本文件学习老板样板的推理方法，不保存其当周结论、热点或固定阈值。适用于日、周、月及专项，必须使用本任务真实注册工具与冻结证据；不增加网络、费用或业务执行权限。

## 从证据走到决策

1. **决策与基线。** 开头说明负责人需要决定什么。列本期/对照期真实日期、时区、站点/平台/品类、币种、订单与订单行粒度、统计定义、采集时刻及缺口。优先完整同星期比较；上市阶段和活动窗口需有来源。相同采集时点不等于相同 T+n。
2. **锁定影响位置。** 双期销售、订单、客单的原值与变化并列。用未舍入值计算：订单效应=(本期单数−前期单数)×前期客单；客单效应=本期单数×(本期客单−前期客单)。两项之和必须等于销售差。显示值按分分配舍入尾差，不能让约数改变决策。净下降含正向抵消时，负贡献可超过 100%；明确分母和抵消，不写成数值 100%。不同边际的贡献不能相加。
3. **沿贡献下钻。** 先看同星期日曲线与平台/品类，再选择能改变行动的地域、设备、支付或小时交叉。完整分页与汇总核平后才称全体；截断结果只展示已知行，未知组不补零。客户身份缺口不能吞掉已知地域和设备数据。图的标题说明要回答的管理问题，单位/双期真实日期/采集时刻/范围在图旁，底表与正文一致。
4. **竞争解释与反证。** 每个重点专题写观察事实、至少一个有力替代机制、预期可见信号、已查结果、尚缺什么、哪项结果会推翻解释。相关性、恢复阈值、前后差异或某平台例外都不是因果证明；PC 等差异群组未满足可比条件时只作描述。优先做已有工具能完成且信息量最高的验证，再提出具体人工补证。
5. **可改变动作。** 每个建议有对象/筛选、责任角色、动作、事实依据、触发条件、投入或风险、复查时点、成功/失败标准、停止条件。事实不足则是补证动作，不能伪装成已验证经营策略。阈值来自已批准政策；否则说明仅为待确认建议及制定依据。数量不固定，不复制样板的 50 单、4 小时或恢复百分比。

## 专题的必查边界

- **Items/客单异常：** 在权限和字段允许时查询平台×品类、头部商品/高额订单、同 SKU 数量/单位/优惠；分开组内客单变化和权重变化。订单客单不等于同规格单位售价，客单增加不能证明涨价、品质更好或需求不敏感；只读工具能查的先查，缺数量或优惠时保持原因未证。
- **供给/履约：** 本业务为订单驱动、无持货库存、供应商月结。核接单能力、页面/渠道可用性、派单与实际交付事件，不建议囤货。周商品销量不能当周末销量。固定脱敏观察队列的真实完成、退款、取消、再入池与新流入分别记；老龄总池不降不等于处理失败。没有历史日末或事件，不能编趋势、完成率或零交付。
- **利润：** Order 原生参考日率与 Admin 主站经营量分别标来源/范围。只有日率而没有同定义分子分母时，不平均成整周利润率；如展示简单日均，必须写“无权日均，非整周率”。不将全站率×主站销售额当结算利润或目标实绩。采购打款/未知类型不变成已核改价成本。
- **官方热点/事件：** 先检查实际工具清单。有可用且已授权的检索/读取工具才取证，优先官方原文；保存链接、发布/事件/生效时间、读取时间、适用平台/地区与期间、事实、可能机制、内部可检验信号和反例。事件发生于期后时，只能用于未来机会，不能解释期内下降；期后发布但回溯期内发生的事件须核实际事件时间与适用性，不能按发布日期误判为期后事件，也不能假称期内已获得该信息。没有工具写“官方情报未开展（工具未接通）”，工具失败写失败；不能写没有热点，更不能复制旧样板。

## 输出兼容与审核

Markdown 采用清楚的“关键判断”“专题”“建议与复查”“缺口”标题。每个建议用独立 R 编号标题；旧表格和 A 编号建议也保留。专项对照区间在主标题明确列完整日期；结构化采用 report_contract=fs-report-v2，summary/findings/actions/reviews 的内容都需证据，research_text 保存完整正文，comparison_period 用 start/end 明确实际对照窗，缺字段写待补。旧结构化合同仍兼容，不要为凑结构重复调用模型或复算已核清算式。原始文本、证据、旧老板版不可覆盖；阅读校正另存版本并列出原问题、正确口径和来源。

出稿前核：数字与方向、贡献闭合、单位/分母、期间与双期日期、T+n、分页/截断、引用是否真能支持本句；逐条审“因为、排除、改善、正常化、提价、库存”等因果或动作词。无法证明就改为待证解释并给可证伪动作，不用大量“持续关注”顶替调查。可见勘误优先于保留的历史原文；成稿、引用存在、调用次数和技能加载不等于经营结论已通过。

使用已审核 Marketing 方法展开具体竞争解释与验证设计：attribution 用于归因窗口与混杂因素，customer-research 只在有脱敏反馈时使用，ab-testing 只提出适合实际样本/期限的可证伪实验，psychology 只能形成假设。最后用 Humanizer-zh 去除空话和重复，保留数字/证据 ID/来源范围/时间/条件/置信程度及建议未执行状态；不把谨慎结论润色成确定因果。
