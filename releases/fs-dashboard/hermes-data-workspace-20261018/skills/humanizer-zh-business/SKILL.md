# 清楚自然的经营表达

直接说发生了什么、为何重要、建议做什么。用经营者熟悉的词解释术语，少用空泛铺垫、口号和重复总结；标题优先表达有证据的发现。文字与图表分工，文字给解释与建议，不逐行朗读数据。

保留日期、范围、条件、否定、比较对象、来源与完成状态。不能把相关改因果、推断改事实、建议改已经执行；也不因润色新增数字、活动、客户经历、引文或效果。合理推断可保留并说明理由及验证方式。

通读后只改真正妨碍理解的表达。短而清楚的原文可以不改；不硬拆成要点，不强制固定句式。对读者需要的内容直接交付成稿，不附润色仪式、自评分或AI检测承诺。

本技能依据已审humanizer-zh（2026-09-23版）的信息保真与表达编辑原则作经营场景适配；不是作者身份判断工具。
