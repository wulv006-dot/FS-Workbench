# 交互HTML呈现指南

复杂报告可输出完整离线HTML；简单查询按需要直接文本回答。不把历史示例当强制模板，不引入固定FS视觉。HTML使用自包含CSS/JS/SVG，无外部字体、脚本、跟踪、网络请求或宿主访问；HTML中的互动只作用于自身报告。

布局随可用容器宽度重排，必要时采用容器查询并保留基础单列布局。字号可使用有上下限的clamp，避免仅用vw造成极窄/极宽视口失真。需要视口高度时考虑移动浏览器工具栏变化，用动态视口单位。图表尺寸与数据密度相称，坐标、标签和图例保持可读；不要只为填满卡片无限拉高。

表格保持表头与数据格关系，使用真实table/thead/tbody/th。窄屏可在有边界的容器内滚动或适配为标注明确的卡片；不使整个页面横向溢出。折叠用可键盘操作的details/summary或等效可访问控件，显示摘要。切换数值、单位和说明同步更新。

校验数值、零点、坐标尺度和正负方向；涨红跌绿同时附正负符号或文字。检查所有查询DOM节点与脚本引用，避免缺失容器导致初始化中断。浏览器测试能力不存在时不能自称交互通过。

来源：已授权modern-web-guidance包，2026-10-18读取responsive-design、responsive-table及此前size-aware-styling。这里只安装审核后的适用方法，不要求模型执行安装命令，不赋予额外网络权限。
