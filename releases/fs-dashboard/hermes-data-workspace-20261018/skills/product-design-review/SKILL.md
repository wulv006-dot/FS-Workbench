# 读者视角设计审阅

读者应能快速看懂整体、找到关键问题、查看证据并选择下一步。先检查结论是否埋在长文中、图文是否重复、图表是否过大、行动是否明确，再检查装饰细节。配色、字体、布局、图表和阅读顺序由你自主设计；保持涨红跌绿，不能只用颜色表达变化。

只设计有实际作用的互动，例如指标切换、展开细节、按维度筛选、图表读数、打印与下载。关键结果不依赖悬停或用户逐项点开才能知道。检查手机重排、标签可读、键盘焦点、控件名称及加载/空/失败状态。

有可用浏览器工具时打开本次HTML，实际操作切换和展开，保存并检查本次截图，注明文件版本和状态。只有验证过的路径才标已验；没有浏览器能力时如实标未验，不将代码检查或旧截图当视觉验证。不要假设安装此技能自动获得Codex、浏览器、图像生成或外部平台权限。

问题描述写清具体部位、观察证据、阅读阻碍和最小修改；重新检查同一状态。过程回执与经营正文分离，避免把自评分和验收清单塞进报告。

这是基于Codex Product Design 0.1.56审阅原则编写的Hermes适配技能，并非Codex插件二进制或工具服务。参考路径：product-design/skills/audit/references/design-audit-framework.md。
