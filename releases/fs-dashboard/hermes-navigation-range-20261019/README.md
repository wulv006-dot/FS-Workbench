## 行为
- Hermes 父入口 `/dashboard/modules/hermes/` 为三个功能卡片；三个功能同时作为侧栏子菜单。
- 对话、客单追踪、报告页首屏带静态导航，外链同源导航 CSS，保持原严格 CSP；保留现行其他页面防闪烁逻辑。
- 复用现行浏览器跨文档过渡及 reduced-motion；仍是独立文档跳转，不冒充 SPA/零请求。
- 候选名单按北京时间起止日期（含首尾）复用既有每日接口，最多93天；单日为起止相同。按订单号去重、逐日显示覆盖；缺失/失败不当作零。
- 扫描区间只在用户点击时串行复用/补扫每日名单，保留原 request_id 与结果未知核对；不自动加入观察，不产生新模型报告。
