# FC Coins 已有证据接入

本批为 FC Coins 策略研究接通真实执行账本、原单成本/优惠券/优惠码与营销核对。新增 `fc.query_pricing_evidence` 三种只读查询；营销继续使用原 `fc.query_marketing_snapshot`。没有新采集器、定时器、价格写入或 UI 改动。

活动维护源为本目录 `source/`，五个精确运行目标见 SOURCE-MAP.json。research、fs_evidence、source_snapshots 从当前服务器完整字节取得后最小修改，保留已上线修复；旧 release 中的同名副本保留作历史，不据此覆盖活动源。业务基准 v7 合并最新 v6 渠道核算和用户本次 Coins-only 说明。

执行账本按原 ID、北京时间区间及分页读取，保留失败/UNKNOWN；后台参数 before/after 不等于独立公开价格暴露。金币订单以 ES 原单 `货币(Gold)` 精确限定，已售券商品、Items、SBC 等不进入金币核算；在金币订单核销的优惠券仍纳入。复用 FS 渠道完成单核算、测试排除及精确成本修正；未知成本不补零。订单/优惠 USD 与覆盖完成单的发货 CNY 各自列示，不跨币种相减，不重复扣优惠，不相加重叠用码/用券组。套餐数量及退款最终结算未留存部分明确待核。

原日报准备机制加入只读账本/成本查询，既有工具、来源关闭合同、并发任务保护和原任务证据冻结继续生效。原采价、自动化开关、10%底线及 SBC 等固定金币联动公式保持；新策略研究不构成停机或削减自动化依据。

验证：`python -B -m unittest discover -s tests -v`。本地检查、正式 CI、合并、生产加载、真实模型和自然周期分开记录；源码存在不代表上线或模型已学会。
