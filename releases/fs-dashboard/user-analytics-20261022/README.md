# 用户分析候选模块

本目录实现购买客户账本、确定性生命周期、冻结快照、权限注入查询、项目比较、成熟二购及两条 Hermes 适配函数。第一批代码候选，尚未连接生产；不能以本目录存在、单元测试通过或页面可打开认定 W0–W6 已完成。

执行依据为《FS_用户看板_规划与Work施工说明_20261022.md》第 17 节。源调查基线 `99bf37c8a23575aabb030b397fbaa6e337a8c9ff`。当前状态见 [CURRENT_STATE](../../../docs/planning/fs-user-analytics-20261022/CURRENT_STATE.md)。

## 已实现的候选行为

- `source/user_source.py` 复用 `channel_source.pages` 与现有 Admin 共享会话，按至多 28 天、固定截止读取原始订单；不调用渠道成本/优惠采集，也不逐邮箱扫描。完整片才事务提交，失败不覆盖已有完整水位。
- `user_store.py` 独立私有 SQLite，按站点和订单号幂等，UID=0 正常入池。邮箱仅去首尾空白；大小写、点和加号保持。随机内部身份、密钥摘要索引与密钥指纹防止无声换身份；原始邮箱不进聚合。完整片重读替换成员，撤销/退款保留修订。
- `user_lifecycle.py` 区间购买=确认首购+确认老客+首购待核；期末四阶段及状态待核互斥。覆盖缺口后的末购不当可靠末购。北京自然日、半开区间、午夜购买优先、多人多次事件、历史截止和 H×24h 成熟二购明确。
- `user_query.py` 冻结聚合与脱敏名单；管理员明细/导出、两种 Hermes 函数使用同版数据。不存在或条件不符的快照不换最新。跨站身份未核时拒绝精确合计，单站继续可用。项目对比涉及整体状态时另核整体读取权限。
- `user_http.py` 供活动宿主薄接线，沿既有登录身份；不启动另一台 API，不从公开请求指定 owner 或获得管理员权限。
- `ui/` 为接上述接口的桌面页面候选，复用 FS 令牌、导航、主题；没有演示经营数字。包含区间和期末两行、每日表、二购分母、项目状态矩阵、脱敏下钻和导出。趋势图形、布局视觉验收、当前 UI 资产核对未完成。
- `user_tools.py` 提供研究函数 schema/call 与普通聊天 register_native，**尚未加入活动研究注册器和原生插件**。网页目前只复制冻结证据指令，正式一键会话接线仍待完成。

## 现场接入顺序

1. W0：在实际服务器运行本目录 `inspect_runtime.py`，只读核对活动文件哈希与共享服务健康。该探针不读取订单，**不能替代**真实字段、站点、退款/欺诈/测试状态、非 FC/卫星站及 30 日规模取样。当前私有配置保留 `activation_status=candidate_requires_W0_status_mapping_and_live_samples`；共享采集入口拒绝该状态，完成真实合同后才按实际结果改为 `W0_verified`。
2. 核真实来源后，私有目录、身份密钥及数据库跟随现有私有备份。不要将构造测试密钥、测试站点 777、游戏 2000 或 fixture 历史起点用于生产。配置中的 history_origins 默认为空；没有完整首购证据不填项目发售日猜测终身首购。
3. 从活动 `range_api.py` 增量挂载 `/users` 和 `/users/private`，构造 `Service(store, authorizer)`；authorizer 必须根据当前 IAM 判断登录主体、范围和管理员身份，不能固定返回 True 或复制服务器 trusted owner 到浏览器入口。导航、Nginx 精确路由由当前发布器生成，必须核当前 CAS，不能复制渠道 release 整包。
4. 验证最近 30 日、FC、另一个真实非 FC 项目及可用卫星站；将真实确认的状态排除、系列、身份和版本映射固定。再接增量、历史修订与回补任务。当前代码只证明“重读付款窗”的退款修正；可靠变更游标、旧订单退款发现及周期核对尚需现场实现，不宣称全历史退款完整。
5. 研究路径增加 `fc.query_user_analytics` 与 schema，绑定当前 owner；普通聊天调用 `register_native`，使用现有可信服务器主体；都调用同一 Service 或其受控聚合入口。接原证据读取与报告持久化，验证真实模型、缺口、同快照数字。一键页面会话沿当前 conversation 合同完成。
6. 沿既有 publisher/锁/CAS/备份最小发布；验证实际入口、普通/管理员、静态资源、两套工具和整组刷新。日切/增量/失败续跑必须真实自然发生后记录，不用模拟或定时器存在冒充。
