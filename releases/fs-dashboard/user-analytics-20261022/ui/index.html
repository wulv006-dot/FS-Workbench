    第一次回购发生在什么时候

    这块怎么读？
    1. 每一批 = 站内首单落在同一个月的客户；「新客」「老客」按首单上的 ES 标记区分。
    2. 回购 = 首单后满 24 小时的另一笔有效订单（当天补单不算）。
    3. 只用「时间已满且数据完整」的客户算比例；没满的人不进分母，显示为斜纹。
    4. 三个天数节点可以改；选「新老对比」时，格子大字是新客，小字是老客。

    沉默后回流：一段时间没买的人，后来回来了吗

    用来验证「1–2 个月沉默，新赛季又回来」

    首单后 天内没买第二单的人，在第 61 到 天之间回来下单的比例

    各批次沉默后回流率

    柱高 = 回流率；柱上数字 = 回来的人数 / 沉默的人数。

    回流带来的复购金额

    回流窗口内的复购订单金额合计（USD）。

    这块怎么读？
    1. 先找出首单后前 N 天内一直没回购的人（沉默的人）。
    2. 再看他们在回流窗口里有没有回来下单。
    3. 只统计首单已满回流截止天数、且数据完整的批次。
    4. 这里的截止天数和「回头率」里的节点是各自独立的设置。
