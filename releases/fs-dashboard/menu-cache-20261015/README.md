# FS 菜单访问缓存

2026-10-15，用户明确授权缓存菜单范围，退出、换账号或权限变化时失效，保留后台鉴权，验证后上线。负责人为本聊天 Codex；消费者为原生首页/分析、模块目录、业务页统一侧栏及账号页。

只缓存当前浏览器标签页中已经成功探测的入口；三种导航共用同一缓存。每次进入页面仍验证现有登录会话，缓存不能授权任何后台请求。用户名、角色、访问组以及账号操作代次共同绑定缓存；账号页成功提交登录、退出或权限操作时清除本标签页缓存并广播失效。其他标签页立即清缓存。现有服务端账号版本/会话撤销机制保持，服务端401/403也清缓存。失败、超时、不可用入口不缓存，存储不可用时回退原探测。

未修改认证后端、权限规则、账号、数据库、业务参数或调度，不重启认证服务。代码变化限于runtime.js、shell.js、navigation.js、hubnav.js与账号app.js；发布沿用已有不可变原生版本和共享UI publisher，旧版本保留。publisher仅扩展精确两个共享UI目标，沿用锁、CAS、备份和回退。

本地25项缓存/边界检查、13项合成浏览器检查、3项发布检查通过；Windows未执行Linux文件所有权校验，必须由CI执行。合成首次20个HEAD入口探测，后续跨模块切页成功入口重复探测0；这不是生产耗时测量。真实账号退出、改权不为测试而执行。

可安全重复检查：node test_cache.cjs；node verify_browser.cjs（本机浏览器环境）；python test_release.py（Linux须满足原publisher所有权要求）。发布使用唯一release-id，成功或结果未知后不得盲目重复apply；先读回对应账本。最终合并、部署和真实入口结果另见DELIVERY.md及deployment/，本文件不单独代表已上线。
