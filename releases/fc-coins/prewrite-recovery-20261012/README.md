# FC 写价前拒绝后的恢复衔接

浏览器超时后，新自动任务可完成全部采集，但旧门禁会在写价前拒绝该任务。原恢复桥接只接受发生在这次新拒绝之后的另一轮采集，导致正常来源仍反复等待。

本次允许同一被严格证明未发送写价的任务，其已完成、有效且新鲜的采集参与恢复观察：核对原任务 ID、同策略 revision、任务开始≤采集≤报价≤写前拒绝，并保留来源、成本、时效、公开价和 UNKNOWN 保护。原失败仍是 failed；两次健康检查后由原定时器创建全新任务，重新采集、预览及通过原 writer。不会重放原失败操作，不新增队列、调度或 workflow。

两份运行源码已于 2026-10-12 09:40:47 北京时间经既有 monitor publisher 锁/CAS/备份/原子替换发布。通知器仅核对当前哈希，不替换；保护代码、策略及发布窗口内六服务 PID 保持。source→runtime 与回退位置见 SOURCE-MAP.json，baseline/ 保留发布前两份源码。
