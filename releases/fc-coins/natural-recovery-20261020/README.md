## 新行为
- 定时正常采集，然后对明确写入前认证失败且无 Player 写账本的旧任务做一次只读复验。既有身份、模型读取、MMOEXP/ALL 六商品及公开金币档位必须通过；预检限时 150 秒，外层 180 秒。
- 本轮资格绑定原失败、原金币执行及 ALL 账本哈希和配置版本；不删除失败，不永久改 gate 为 ready。
- 来源/成本/报价仍走原校验。Coins 按最新报价写，后续 Player 按最新确认实际金币价计算。
- 无金币价格变化时，使用新自然轮次证据及确定性 recovery ID 补 Player；原失败有账本则绝不走此路径。已确认或未知写入不盲重放。
- 只读采集/报价/preview 明确失败且无写入痕迹时，允许下一正常间隔重新完整采集；不把进程中断/未知写入当作安全重试。
- 复验失败当轮结束，下轮重新检查；门禁恢复不导致下一 timer tick 提前再跑一轮。
