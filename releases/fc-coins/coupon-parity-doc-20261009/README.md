## 口径本身

`L`、`U`、`I` 一律取**页面挂价（券前口径）**。券前价与无券价是同一种东西的两种叫法：

- 站点**有券**时：页面挂价 = 券前价（券后价 = 券前价 × (1 − 折扣)，另计）
- 站点**无券**时：页面挂价 = 券前价 = 券后价 = 无券价，**三者合一**

因此竞品**撤券或加券都不改变对标口径**，锚定价 `L` 可直接沿用，无需换算或特殊处理。
