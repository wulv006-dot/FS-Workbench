# MLB 新卡上架 · 本机执行器

密码启动时在终端输入，或由本机环境变量 `MLB_AGENT_PASSWORD` 提供；不要把口令写入启动脚本或共享文档。当前 HTTP 入口在升级为 HTTPS 前不适合通过公网发送登录口令。

网页端（`https://47.85.224.112/mlb/`）负责**派活**，这个执行器负责**干活**。

---

## 一、为什么要有这个执行器

采集必须跑在**你自己的电脑**上，不能放在服务器：

|              | 服务器（阿里云 47.85.224.112）               | 你的办公电脑                 |
| ------------ | ------------------------------------ | ---------------------- |
| 访问 showdd.io | 命中 Cloudflare `chl_page` JS 挑战，拿不到数据 | 住宅 IP，HTTP 200 直接拿到真页面 |
| 实测响应         | 挑战页                                  | 432 KB 完整页面            |

以上是旧服务器的测试结论；新服务器出口的 showdd 采集结果尚未复核。当前架构仍将采集留在本机：  
服务器托管网页 + 排队，本机负责真正抓 showdd。

## 二、安装（每台电脑只需做一次）

需要 Python 3.8 以上。

```bash
# 1) 解压 agent.zip 到任意目录，进入该目录
cd mlb_agent

# 2) 装依赖
pip install -r requirements.txt

# 3) 装 Playwright 的浏览器内核（光装 pip 包不够，这步必做）
python -m playwright install chromium
```

> 装不上 chromium 也没关系：执行器会自动去找本机已装的 Chrome / Edge。

## 三、跑起来

### 推荐：常驻轮询

挂在后台就行，网页上派的任务它会自动认领。

```bash
python mlb_agent.py --server https://47.85.224.112 --user wulv --agent 我的电脑 --show
```

> **`--show` 是必需的，别去掉。**  
> showdd 有 Cloudflare 人机验证，无头模式会被直接拦下。  
> 带上 `--show` 后首次会弹出浏览器窗口，手动点一下通过验证；  
> 通过后登录态会存进工作目录的 `browser_profile`，**之后就不再要求验证了**。  
> 代价只是留一个浏览器窗口开着——挂着别关就行。

### 调试：只跑一次

```bash
python mlb_agent.py --server https://47.85.224.112 --user wulv --agent 我的电脑 --show --once
```

### 本地自测：不连服务器，直接抓一批看看

```bash
python mlb_agent.py --self-test --rate 3.89 --show
```

### Excel 模板从哪来

上架用的模板是 mmoexp 后台导出的 `mould-create_*.xlsx/.xlsm`（16 列表头，  
第 16 列 `分类ID（勿改）` 对 MLB 是 **8233**）。执行器按下面顺序找，**第一个命中的就用**：

| 优先级 | 来源                                                   | 说明                   |
| --- | ---------------------------------------------------- | -------------------- |
| 1   | 网页随任务上传的模板                                           | 最省事，网页勾一下就带上         |
| 2   | `--template` 指定的路径                                   | 手动指定时用               |
| 3   | 工作目录 `~/MLB新卡上架/`                                    | 网页下发时会自动落到这里         |
| 4   | `~/Desktop/产品模型/MLB/`                                | **运营日常导出模板的地方，会自动扫** |
| 5   | `~/Desktop/产品模型/`、`~/Documents/MLB新卡上架工具/generated/` | 兜底                   |

同目录下多个候选时，按**修改时间最新的**优先。

> ⚠️ 认模板只看**文件名以 `mould-create` 开头**且后缀是  
> `.xlsx` / `.xlsm` / `.xls`。所以别把模板改名成别的名字。
>
> 找不到时报的错就是上面那句「没有可用的 Excel 模板」，把它列出的目录看一眼，  
> 通常是模板还没导出，或者存到了别的目录。

### 常用参数

| 参数                      | 说明                                                      |
| ----------------------- | ------------------------------------------------------- |
| `--server`              | 服务器地址，默认 `https://47.85.224.112`（会自动补 `/mlb` 前缀）。**必须 https** |
| `--user` / `--password` | 网页登录凭据。密码有三种给法，见下方「密码怎么给」                               |
| `--manual-login`        | 不自动登录，弹 Chrome 让你手动登一次，程序接管 Cookie（自动登录一直失败时用）      |
| `--agent`               | 本机标识，网页上靠它区分是哪台机器在跑；不填会自动生成                             |
| `--workdir`             | 工作目录：存浏览器登录态（`browser_profile/`）和网页下发的模板。默认 `~/MLB新卡上架` |
| `--template`            | 指定本地 Excel 模板路径。**网页随任务上传模板时不需要填这个**                    |
| `--interval`            | 采样间隔秒数，默认 120（**不要调小**，价差靠间隔拉开）                         |
| `--poll`                | 无任务时的轮询间隔秒数，默认 15                                       |
| `--once`                | 跑一次就退出                                                  |
| `--show`                | 显示浏览器窗口（**生产环境必须带**，用于过 Cloudflare 验证）                  |
| `--self-test`           | 本地自测，不连服务器                                              |
| `--batch`               | 指定批次，如 `9-22-26`；不填则自动找最新批次                             |

> ⚠️ `--workdir` 一旦定下就不要改：登录态存在里面，换目录等于要重新过一遍验证。

## 四、它会做什么

1. 轮询服务器任务队列，领到任务
2. 用 Playwright 起真实浏览器访问 showdd，定位最新批次的新卡
3. 对每张候选卡**连续采样 3 次官方 Buy Now 价**，每次间隔 ≥ 120 秒
4. 取 3 次采样的**中位数**，按公式算售价：
   ```
   售价 = (中位成本 / 100000) × 汇率 × 1.1     四舍五入到分
   ```
   - 低于 **$0.50** 的卡直接过滤掉，不上架
   - 汇率默认 `3.89`（老大 2026-10-05 确认，此前为 2.65），任务下发时可覆盖
5. 追加写入 Excel 模板 —— **严格保留原文件名、扩展名、工作表结构和已有行**
   - 模板来源优先级：**网页随任务上传的模板** → `--template` 指定的本地文件 → 工作目录里最近的 `mould-create*.xlsx`
6. 本地校验通过后，把结果 + Excel 回传给服务器，网页上即可下载

### 字段口径（关键，别搞错）

| showdd 字段 | 含义                  | 用不用         |
| --------- | ------------------- | ----------- |
| `Sell`    | 官方 Buy Now（= 我们的成本） | ✅ **用这个**   |
| `Buy`     | Sell Now（玩家卖出价）     | ❌ **绝对不要用** |

## 六、常见问题

**Q：双击「启动执行器.bat」没任何反应，窗口一闪就没了？**  
先看启动时打印的 Python 路径和报错。若确实一闪而过，在本目录按住 `Shift` 右键  
→打开 PowerShell→ 输入 `.\启动执行器.bat` 就能看到完整报错。

常见原因与处理：

- **没装 Python**：装的时务必勾选 “Add Python to PATH”，然后重开窗口再试。
- **依赖没装成**：手动执行 `py -3 -m pip install -r requirements.txt`。
- **密码没给**：见下一条。

**Q：黑窗口里出现满屏 `C:\...> 命令` 和 `◆◆` 乱码？**  
这是 bat 文件本身的编码/换行坏了（不是你的操作问题）。  
cmd.exe 读 `.bat` 用的是控制台代码页（中文 Windows 为 936/GBK），不是 UTF-8 ——  
只要 bat 里有非 ASCII 字符、或带了 UTF-8 BOM、或用了 LF 换行，就会解析错乱。  
判断办法：正常的 bat 窗口里**只会**打印 `[OK]` / `[*]` 这类提示，  
不会把命令本身回显出来。重新从网页下载一份 `agent.zip` 解压即可（已修复）。

**Q：明明建了密码文件，却还要我输密码？**  
注意记事本会**自动加扩展名**：你以为存的是 `.mlb_pass`，实际落盘是 `.mlb_pass.txt`。  
现在两种名字都认，启动时会打印 `Password source: file .mlb_pass.txt` 告诉你用的是哪个。

**Q：报「登录失败（HTTP 303/308）：被重定向到登录页」？**  
2026-10-12 排查结论：nginx 对 `/__auth/` 加了强制 HTTPS  
（`if ($scheme = http) { return 308 https://... }`），门户 Cookie 又是 `secure_cookie=True`。  
所以**走 http:// 登录请求根本到不了门户**，在 nginx 就被拦掉。  
现在执行器会自动把 `--server` 升级成 `https://`，一般不会再遇到。  
若仍看到 303/308，检查 bat 里是不是还写着 `http://`。

**Q：密码一直不认，就想手动登录行不行？**  
可以，这也是现在支持的正规路径：  
双击 `启动执行器.bat` → 选 **2**，程序会弹一个 Chrome 窗口打开登录页，  
你自己输入账号密码登录，程序检测到 `MMOEXP_AUTH` Cookie 后自动接管，  
不用再输密码。Cookie 是「记住登录」30 天，之后选 1 自动登录一般也能过。  
等价命令行：`python mlb_agent.py --server https://47.85.224.112 --user wulv --show --manual-login`

**Q：报「尝试次数过多，账号/IP 被临时锁定（约 5 分钟）」？**  
门户有失败次数上限（连续 6 次锁定 5 分钟）。  
等 5 分钟自动解锁，然后**确认密码一次输对再启动**，别连续重试。  
若不确定密码，先用浏览器打开 `https://47.85.224.112/__auth/login` 手动登一次。

**Q：网页显示执行器离线？**  
按顺序排查：

1. **执行器进程在跑吗**？看那个黑窗口是否还在、有没有持续打印日志。
2. **日志里有「已连接服务器，心跳正常」吗**？没有就是没连上，按第 3 步。
3. **是密码问题吗**？用 `启动执行器.bat` 启动时会提示输密码；  
   想免输就把密码写进同目录的 `.mlb_pass` 文件（单独一行，  
   记事本存成 `.mlb_pass.txt` 也能被识别）。
4. **还是不行**：浏览器打开 `https://47.85.224.112/mlb/` 能进说明服务是好的，  
   把黑窗口里的报错原文发出来。

> 心跳超过 150 秒收不到，网页就判定离线。执行器进程被关掉、电脑休眠、  
> 或网络断掉都会看到离线。

**Q：报「网站要求人工验证」？**  
漏了 `--show`。加上重跑，在弹出的窗口里点一下验证；通过后登录态会存下来。

**Q：第一次跑卡在采样不动？**  
确认带 `--show` 且浏览器窗口真的弹出来了。若窗口被最小化或被其他窗口完全遮挡，  
Cloudflare 的挑战可能不自动通过 —— 把它拿到前台点一下即可。

**Q：报「没有可用的 Excel 模板」？**  
执行器会自动扫这几个地方（详见上文「Excel 模板从哪来」）：  
工作目录 `~/MLB新卡上架/` → **`~/Desktop/产品模型/MLB/`** → `~/Desktop/产品模型/`  
→ `~/Documents/MLB新卡上架工具/generated/`。  
多半是模板还没从 mmoexp 后台导出，或存到了这些目录之外。  
最省事的做法是**在网页提交任务时勾选上传模板**。  
另外注意：模板文件名必须以 `mould-create` 开头、后缀 `.xlsx`/`.xlsm`/`.xls`，改名了就认不出。

**Q：报 `playwright` 装不上？**  
执行器会自动找本机的 Chrome / Edge。仍失败的话执行  
`python -m playwright install chromium` 单独装内核。

**Q：抓到的价格是 0 或明显不对？**  
检查是不是误用了 `Buy`（Sell Now）字段。成本必须取 `Sell`（官方 Buy Now）。

**Q：Excel 格式被改坏了？**  
执行器用 `keep_vba=True` 处理 `.xlsm`，会保留宏和工作表结构。  
回传前会做校验，不合格会报错拒绝提交。

**Q：任务一直排队不动？**  
没有任何执行器在线。至少启动一个执行器。

**Q：执行器日志停在某一步很久？**  
页面级超时已设为 20 秒、导航 120 秒，正常不会挂死。若确实卡住，  
杀掉后重启即可；重启会复用已存的登录态，通常不用重新验证。

## 七、给运维的信息

- 执行器是**只读抓取 + 写本地 Excel**，不改动 showdd 上任何东西
- 服务器侧只做排队和文件暂存，不碰数据源
- 上传大小上限 40 MB（`MAX_UPLOAD`）
- 任务结果里的 Excel 以 base64 回传，服务器落盘后即从数据库剥离，避免库膨胀
- 服务器出口 IP 在 Cloudflare 侧被拦，**采集只能在本机做**，这不是配置问题
