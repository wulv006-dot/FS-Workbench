没装执行器？点这里看怎么装
  1. 下载 执行器压缩包，解压到任意目录
  2. 装依赖（需要 Python 3.8+）：
    pip install -r requirements.txt
    python -m playwright install chromium
  3. 起一个常驻进程（Windows 也可直接双击 启动执行器.bat）：
    python mlb_agent.py --server http://47.85.224.112 --user wulv --agent 我的电脑 --show；启动时输入工作台密码。
  4. 首次遇到 Cloudflare 验证会出现浏览器窗口，手动点一下通过即可（之后会记住登录态）
  5. 把这个窗口挂着别关，回来刷本页就能看到任务被领走

换电脑只用把上面第 2~3 步再跑一遍，--agent 名换掉即可（可以多台一起挂）。
